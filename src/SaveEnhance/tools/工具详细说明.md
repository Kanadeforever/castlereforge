# Castle_SaveEnhance 随包工具详细说明

## `PatchUtil.h`

运行时机器码安全修改工具。

原则：

1. 写前验证原版字节；
2. `VirtualProtect` 临时允许写；
3. 写完 `FlushInstructionCache`；
4. 恢复原页保护；
5. 互相依赖的多项补丁作为事务；
6. 当前失败项也可能已经写过，所以回滚包含失败项自身。

提供：

- `BytesEqual`；
- `WriteBytes`；
- `ValidatePatchSet`；
- `ApplyPatchSet`；
- `RestorePatchSetToOriginal`；
- 5-byte rel32 CALL；
- 6-byte CALL+NOP。

## `PluginLog.h`

无 CRT UTF-8 日志工具。

不依赖 iostream/stdio，直接使用 KERNEL32 文件 API，把每次启动日志写到 ASI 同目录 `Castle_SaveEnhance.log`。

## `Win32Mini.h`

只声明 SaveEnhance 真正需要的最小 Win32 类型和 KERNEL32 API，不手工复制整个 Windows SDK。

正式 Windows 构建仍用真实 `kernel32.lib`；这个头只是减少头文件/CRT依赖并允许第二套交叉语法检查。

test7 让日志与状态文件共用 `BuildModuleFilePath`。状态文件使用
`..\multimedia\save\.NEXTAUTOSLOT`，并兼容读取/删除 test6 旧 `exe\Save` 文件。
`WritePrivateProfileStringW` 已删除，因为自动槽游标不再写入 INI。

## `Castle_PadSupport_API.h`

Controller 公共 API v1 的消费端 ABI 副本。

SaveEnhance 只读取函数表，不写 Controller 私有状态，也不修改 PadSupport 模块。
保留槽手柄焦点只读取 `ActionDown/ActionPressed/GetControlMode/AllowsExternalUiInput`，然后在
SaveEnhance 自己链入的 RPG.exe SaveAction Hit/Event wrapper 中处理“读档/取消”。

核心按钮编号：

- START=5；
- R3=6；
- RB=8。

## `verify_saveenhance_candidate.py`

只读静态验证器，不修改输入文件。

检查：

- RPG SHA/PE/ImageBase；
- 10 个固定菜单点；
- 2 个循环分页点；
- 5 个 CALL；
- SaveAction vtable；
- save gate；
- SaveSlot/LoadSlot 前缀；
- `%03d`/Save/.TSF；
- MiscInfo 解码与 +0x3C2；
- ASI PE32/i386/DLL/入口；
- **Export Table 必须包含 `InitializeASI`，确保 Castle Mod Loader 会调用正式初始化；**
- Import Table 只 KERNEL32；
- KERNEL32 名称没有 `_Foo@N` 装饰；
- 无 CRT；
- user32/winmm 不静态导入。

当前还会确认必需 KERNEL32 导入齐全，并把以下两项设为硬检查：

- `WritePrivateProfileStringW` 必须不存在，证明 `NextAutoSlot` 没有回到 INI；
- ASI 必须包含 UTF-16LE 的 `..\multimedia\save\.NEXTAUTOSLOT` 路径标记；
- 必需 KERNEL32 导入必须包含 `CreateDirectoryW/DeleteFileW/GetLastError`。
- ASI 必须包含 test7 独立保留槽手柄焦点日志标记，防止误链接迁移前对象。

### 用法

```text
python tools\verify_saveenhance_candidate.py ^
  --rpg "路径\RPG.exe" ^
  --miscinfo "路径\Public\MiscInfo.ENC" ^
  --asi "mods\asi\Castle_SaveEnhance.asi"
```

可加：

```text
--json-output "静态验证结果.json"
```

返回码：0=全 PASS，1=检查失败，2=输入不存在。

静态工具不能证明实机 UI/剧情状态正确，不能替代《实机测试清单.md》。

## test4 验证器新增检查

`verify_saveenhance_candidate.py` 在 test4 除既有地址、PE32/i386、`InitializeASI` 与无 CRT 检查外，还要求最终 ASI 的 KERNEL32 导入包含并保持未装饰名称：`ReadFile`、`GetFileSize`、`GetProcessHeap`、`HeapAlloc`、`HeapFree`。这些 API 只用于可选外置 PCM WAV 的内存音量缩放。

## test7 构建与状态文件检查

`src\SaveEnhance\build.bat` 直接使用本机登记的 MSVC 19.51 x86 编译器和 x86
`kernel32.lib`，不要求先打开 Developer Command Prompt。最终只把 ASI 和 `templete` 中的 INI
输出到仓库根 `build`，不复制 Markdown。临时文件只进入 `src\SaveEnhance\_build`，并和
`tools\__pycache__` 一起在成功或失败后删除。脚本无注释，只有 `echo` 行使用中文；构建后检查
PE32、DLL、非零入口和 `InitializeASI` 导出。

test7 保持环形游标为 Win32 小文本文件；验证器继续要求 `WritePrivateProfileStringW` 不存在，
完整导入表仍必须只属于 KERNEL32，且保持无 CRT。
