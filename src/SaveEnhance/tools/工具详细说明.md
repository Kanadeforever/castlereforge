# Castle_SaveEnhance 随包工具详细说明

## `PatchUtil.h`

运行时机器码安全修改工具。

原则：

1. 写前验证原版字节；
2. `VirtualProtect` 临时允许写；
3. 写完 `FlushInstructionCache`；
4. 恢复原页保护；
5. 互相依赖的多项补丁作为事务；
6. 当前失败项也可能已经写过，所以回滚包含失败项自身。

提供：

- `BytesEqual`；
- `WriteBytes`；
- `ValidatePatchSet`；
- `ApplyPatchSet`；
- `RestorePatchSetToOriginal`；
- 5-byte rel32 CALL；
- 6-byte CALL+NOP。

## `PluginLog.h`

无 CRT UTF-8 日志工具。

不依赖 iostream/stdio，直接使用 KERNEL32 文件 API，把每次启动日志写到 ASI 同目录 `Castle_SaveEnhance.log`。

## `Win32Mini.h`

只声明 SaveEnhance 真正需要的最小 Win32 类型和 KERNEL32 API，不手工复制整个 Windows SDK。

正式 Windows 构建仍用真实 `kernel32.lib`；这个头只是减少头文件/CRT依赖并允许第二套交叉语法检查。

## `Castle_PadSupport_API.h`

Controller 公共 API v1 的消费端 ABI 副本。

SaveEnhance 只读取函数表，不写 Controller 私有状态，不做输入注入。

核心按钮编号：

- START=5；
- R3=6；
- RB=8。

## `verify_saveenhance_candidate.py`

只读静态验证器，不修改输入文件。

检查：

- RPG SHA/PE/ImageBase；
- 10 个固定菜单点；
- 2 个循环分页点；
- 5 个 CALL；
- SaveAction vtable；
- save gate；
- SaveSlot/LoadSlot 前缀；
- `%03d`/Save/.TSF；
- MiscInfo 解码与 +0x3C2；
- ASI PE32/i386/DLL/入口；
- **Export Table 必须包含 `InitializeASI`，确保 Castle Mod Loader 会调用正式初始化；**
- Import Table 只 KERNEL32；
- KERNEL32 名称没有 `_Foo@N` 装饰；
- 无 CRT；
- user32/winmm 不静态导入。

### 用法

```text
python tools\verify_saveenhance_candidate.py ^
  --rpg "路径\RPG.exe" ^
  --miscinfo "路径\Public\MiscInfo.ENC" ^
  --asi "mods\asi\Castle_SaveEnhance.asi"
```

可加：

```text
--json-output "静态验证结果.json"
```

返回码：0=全 PASS，1=检查失败，2=输入不存在。

静态工具不能证明实机 UI/剧情状态正确，不能替代《实机测试清单.md》。

## test4 验证器新增检查

`verify_saveenhance_candidate.py` 在 test4 除既有地址、PE32/i386、`InitializeASI` 与无 CRT 检查外，还要求最终 ASI 的 KERNEL32 导入包含并保持未装饰名称：`ReadFile`、`GetFileSize`、`GetProcessHeap`、`HeapAlloc`、`HeapFree`。这些 API 只用于可选外置 PCM WAV 的内存音量缩放。
