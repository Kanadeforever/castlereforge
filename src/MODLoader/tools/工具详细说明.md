# 模组加载器工具详细说明

## 结构与目标版本检查

`preloader_check.py` 使用 Python 标准库检查当前源码、正式发行 PE、图标资源、TOML 编辑器、
日志路径及 ASI 两阶段启动协议。可以额外指定只读 RPG.exe，以检查 SHA、入口字节、生命周期
断点和注入空间。运行方法：

```text
python src/MODLoader/tools/preloader_check.py "参考资料/Castle/exe/RPG.exe"
```

该工具不启动游戏，不修改源码、配置或参考文件。任一检查失败返回 1；成功返回 0。未指定 EXE
时只验证当前源码与发行文件，不能把跳过的游戏版本检查算作通过。

源码聚合 SHA 保护的是 Core、Locale、Overrides 等游戏进程侧文件。当前修改这些文件后必须先
复核差异，再更新基线；不能为了消除失败直接复制新哈希。GUI 另由行为与结构检查保护。

## 编辑器 Unicode 行为检查

`toml_editor_check.py` 从 `launcher_gui.c` 提取实际 `toml_utf16_is_valid_` 函数，用 MSVC 编译小型
测试宿主并执行 16 个用例。测试的是生产 C 函数，未复制另一套验证算法。

在已初始化的 Visual Studio 开发者命令行中运行：

```text
python src/MODLoader/tools/toml_editor_check.py
```

要求 Python、cl.exe 和对应 C 标准库；不依赖 RPG.exe、Runtime DLL 或 GUI。用例覆盖空文本、
普通汉字、合法扩展字符代理对、孤立高/低代理项、错误配对、可选输出指针，以及 CR、LF、CRLF
和混合换行的错误行号。测试临时源码和二进制仅写系统临时目录，正常结束自动删除。

返回码：0 为通过，2 表示缺少编译器，其它非零值表示编译或用例失败。测试进程有超时限制。
它不能替代 RichEdit 的真实交互测试；仍需人工核对长注释自动折行、颜色、错误行选择、BOM
保留与保存失败后原文件不变。

构建说明仍以 `src/MODLoader/readme.md` 为唯一入口，完整接档见 `docs/runtime/截至该版本的完整接档.md`。
