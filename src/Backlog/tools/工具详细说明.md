# 工具详细说明

## 工具位置

最新稳定版：`src/backlog/工具/backlog_check.py`。

编译内容包镜像：`src/backlog/编译内容/工具/backlog_check.py`。同目录带本说明，单拿测试包也能理解用途。

## 运行

从仓库根目录执行：

```powershell
python src\backlog\工具\backlog_check.py
```

默认读取仓库参考 RPG.exe、编译内容 ASI 和源码目录。也可指定：

```powershell
python src\backlog\工具\backlog_check.py `
  --game "D:\Castle\RPG.exe" `
  --asi "D:\Castle\mods\asi\Castle_Backlog.asi" `
  --source-root "src\backlog\源码" `
  --json "检查结果.json"
```

## 检查内容

### RPG.exe

- SHA-256 是否在两份白名单；
- 是否 PE32/x86、image base 是否 `0x400000`；
- `0x403C60/0x403E30/0x404800/0x40B150` 入口机器签名；
- `0x40486E` F-Talk draw CALL 与 `0x4049FF` 正文 draw CALL；
- `0x460298` 的 update/draw vtable。

### ASI

- PE32/x86 与入口；
- 导入 DLL；
- 禁止 SDL、MSVCRT、UCRT、VCRuntime 强制导入；
- 只允许 KERNEL32/USER32；
- 版本和动态 SDL 诊断字符串。

### 源码包

- 必需 C/H/INI/build/readme 是否齐全；
- 代码文件名是否 ASCII；
- 每个 C/H 是否至少存在中文块注释；
- INI 是否包含公开默认键位。

## 输出与退出码

每项打印 `[PASS]` 或 `[FAIL]`。全部通过返回 0；任一失败返回 1，适合放进构建或发布脚本。`--json` 只在用户明确指定时写文件，默认全程只读。

## 依赖与安全

只使用 Python 标准库，不安装包、不联网、不修改 EXE/ASI/源码。PE 解析器是为本工具写的最小只读实现，不作为通用 PE 编辑器。

## 维护规则

增加 EXE 版本时不能只加 SHA。必须先证明地址、调用约定、页面缓冲、说话人字段、两个现代绘制 CALL 和 vtable 协议一致，再更新源码预检、工具、地址文档、完整接档和测试清单。工具版本与编译内容包必须同步。
