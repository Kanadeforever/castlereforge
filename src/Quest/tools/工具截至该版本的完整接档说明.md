# Castle_Quest 工具层截至当前版本的完整接档说明

## 1. 当前版本边界

当前源码包只保留一个仍属于现行研究工作流的自制工具：

```text
CastleScriptAnalyzer.py
版本：v0.1.5
```

它是**只读的原版资源、脚本和事件空间事实导出器**。它不修改游戏文件，不修改 Quest TOML，也不参与 Ctrl+F8 热重载。

从 dev6zd 起必须牢记：

> 每条任务运行数据固定为“详细 `Qxxx.toml` + 同名 `Qxxx_addon.toml`”。Base 保存原版链和 Stage Route，Addon 保存人工插入/局部覆盖；运行时仍不存在独立 `routes.toml`。

当前数据版本：Base `format_version=7`，Addon `format_version=2`；任务与阶段身份字段统一为 `quest_id` / `stage_id`，Addon 的 `player_notes` 支持标准多行字符串数组。

## 2. CastleScriptAnalyzer.py 当前职责

分析器在既有 Map/EVE/SCI/MSG/DAT、GameVar、Item、商店、炼化等事实导出基础上，v0.1.5 继续提供原版 SF2 Section0 接触判定几何，并把它与 Entity SCI 的 EA/EB/Event 关联成原版事件空间锚点事实。

这些事实用于回答例如：

- 当前场景里哪个 SCI 对象承载某个 Runtime Event；
- 它是 `TOUCH_EA` 还是 `MANUAL_EB`；
- TouchBox 原始几何是否存在；
- 离线世界坐标和事件编号是什么；
- 哪一条研究 Route 有原版物理事件绑定证据。

研究冻结层的完整 1116 条条件化 Route、历史绑定报告和相关 CSV 保存在：

```text
docs/任务系统/研究/冻结任务数据库/
```

它们是**研究证据池**，不是运行数据库。dev6zd 仍只把某个原版 Base Stage 实际需要且已经达到运行安全标准的边写入该任务 TOML 的 `[[stage.route]]`；Addon 当前不维护跨场景 Route。

```

```

## 4. 已退出的旧工具

### 4.1 QuestDataConverter.py

历史用途：严格 CSV ↔ 多文件 TOML 转换。

从 dev6x 起退出，dev6z 继续保持退出。原因是：

```text
详细 Base + 同名 Addon = ASI 直接运行源；日常人工调整优先写 Addon
```

如果恢复 CSV 转换器，就会重新制造第二套权威源，并可能覆盖实机调试后直接修改的任务 TOML。

### 4.2 RouteNativeBindingBuilder.py

历史用途：把原版事件绑定研究结果写回旧 `maintenance/路由.csv`。

它同样退出现行工作流。当前做法是：

```text
研究层事实/1116 Route
        ↓ 人工或工具辅助取证
对应 Quest 的 [[stage.route]]
        ↓
ASI 直接读取
```

如果未来需要重新制作“研究 Route → Stage-local Route”的辅助工具，它只能作为**候选生成/审计工具**，不能自动覆盖现行 Quest TOML，除非用户明确要求并经过逐任务复核。

两项旧工具的历史说明保留在：

```text
docs/任务系统/历史开发文档/旧工具说明/
```

只用于追溯旧版本。

## 5. 工具纪律

- 分析器只输出事实，不凭 NPC 名字或攻略叙述猜任务语义；
- EVE 文件槽 0 基、Runtime Event 1 基的编号规则不得破坏；
- 资源覆盖继续以有效资源视图为准；
- 研究 CSV/TOML 是证据，不得重新升级成运行任务权威源；
- 任务运行数据永远直接维护 `src/Quest/templete/Castle_Quest/Q*.toml`；
- 自动 `TOUCH_EA` Marker 即使有离线坐标证据，也必须在运行时重新确认当前 RuntimeEntity 且 TouchBox 有效；
- `manual_world` 是明确的人工作者意图，和自动离线回退不是一回事。

## 6. 下一步工具需求

目前没有必须新增的现行工具。后续若 Stage-local Route 数量继续增长，可以考虑增加一个**只读审计器**：检查每个 Stage 的 Route 是否能到达 `stage.target.scene`、是否存在重复物理出口、是否有无法运行的自动 Event 绑定。该工具只能报告问题，不应成为新的数据中转层。
