# RuntimeSDK 工具详细说明

## runtime_sdk_check.py

### 用途

本工具检查 RuntimeSDK 的源码合同、公共 ABI、PE 形状和 build_all 发行树。它不访问只读参考资料，
不修改源码，也不运行游戏。

### 当前检查内容

1. 全部公共服务头、实现、测试、构建脚本和说明存在；
2. magic、版本、结构大小和关键函数名没有丢失；
3. 公共头不泄露 windows.h、STL、size_t 或 C++ bool；
4. Runtime DEF 只导出 CastleRuntime_GetApi；
5. 中文 BAT 注释/echo 行末两个半角空格；
6. 无 CRT memcpy/memset 对象进入正式链接；
7. FARPROC 转换没有回到 Clang 拒绝的直接强转；
8. Schedule Bootstrap/Loader-ready 闸门合同存在；
9. Log、Clock、Input、GameState、Save、Overlay、File、Module、TOML 合同存在；
10. `--require-dll` 检查 PE32/i386、DLL、非零入口、唯一导出和 KERNEL32-only；
11. `--require-release` 检查正式 Runtime/ASI、TOML、Quest 数据、SaveEnhance 随包说明；
12. 发行目录不存在旧官方 INI 和 obj/lib/exp/ilk/pdb；
13. `build/mods/logs` 目录存在。

### 与编译宿主的分工

文本检查只能证明合同符号还在。`abi_layout_test.c` 让四种编译模式真实计算大小和偏移；
`runtime_host_test.c` 真实加载 DLL 并调用服务；其它测试覆盖 Entry Gate、Client、Bootstrap 和故障。

三层任一失败，构建都必须失败，不能删除检查让输出变绿。

### 单独运行

```bat
python tools\runtime_sdk_check.py
python tools\runtime_sdk_check.py --require-dll
python tools\runtime_sdk_check.py --require-release
```

工具会从自身路径向上定位仓库根，不依赖当前工作目录。

### 输出和退出码

- `[PASS]`：检查通过；
- `[FAIL]`：合同不满足；
- `0`：全部通过；
- `1`：存在失败；
- `2`：无法定位仓库。

### 维护规则

- 新增接口时同步公共头、布局测试、宿主行为测试、检查器和设计文档；
- 新增正式插件时同步 build_all 发行清单；
- 不把当前 PASS 数写成永久协议；
- 工具代码继续使用详细简体中文注释；
- 新职责明显不同的工具可以拆文件，但必须继续放在本 tools 目录并更新本说明。
