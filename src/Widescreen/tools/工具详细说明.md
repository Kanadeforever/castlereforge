# Widescreen 工具详细说明

## v0.12.1 鼠标行为宿主（2026-09-13）

`pointer_behavior_test.c` 直接编译生产 widescreen.c；用宿主变量替换游戏外部地址，不分配或注入
真实 RPG.exe。7,928 条断言覆盖 854/1120 每个横向像素的 UI/世界坐标、模态当帧侧区关闭、装饰区
按住后移入中央、窗口消息、原版768行距、边缘鼠标只画一次、backing恢复及主鼠标队列保序删除。
假绘制器只验证调用与像素搬运，不验证实际游戏的 SF2 图案，最终仍要实机。

在仓库根执行：

```text
python src/Controller/tools/run_input_behavior.py --source src/Widescreen/tools/pointer_behavior_test.c
python src/Widescreen/tools/widescreen_check.py --root . --exe 参考资料/Castle/exe/RPG.exe
```

共用 Controller 的测试启动器只是开发工具复用，Widescreen 运行时仍不依赖 Controller。
启动器使用 vswhere/PATH，不含本机编译器路径；产物在临时目录，失败返回非零。
静态工具新增验证0x408830、0x408885、0x40886A、0x43DF3A和0x43E189原字节，当前73项通过。

## widescreen_check.py

这是宽屏业务的只读静态协议检查器，只依赖 Python 标准库。它验证目标 RPG.exe、宽屏几何、
CameraPlan、电影式侧区、配置键、构建脚本和可选 ASI 产物，不修改任何文件。

当前版本已适配主仓目录：

```text
src/Widescreen/source
src/Widescreen/templete/Castle_Widescreen.toml
build/mods/asi/Castle_Widescreen.asi
```

若 build_all 尚未打包，也会回退检查仓库根 build 的单项构建产物。工具仍兼容旧独立归档的
“源码/编译内容”目录，但旧 INI 不是当前正式路径。

用法：

```bat
python tools\widescreen_check.py --root <仓库根> --exe <RPG.exe>
```

当前 RuntimeSDK 边界：Widescreen 只拥有两处 DirectDraw 重建 CALL 和自身 Bink/显示业务，
`0x44A9C6/0x44A9E6` 只作为原版协议检查，正式运行所有权属于 Runtime Render。配置检查使用
Castle_Widescreen.toml；Runtime/公共 ABI 的完整检查由 RuntimeSDK 工具负责。

输出 `[PASS]/[FAIL]` 并用 0/1 退出码表示结果。静态 PASS 不能替代 16:9、21:9、对白、Battle、
切图和 Quest Marker 的实机验收。
