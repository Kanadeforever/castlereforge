## 9. 版本间静态检查条目演进要点


- v0.4 -> v0.5：新增主动交互 CALL 锚点（0x00409982 -> 0x0040b230）与 source+0xEB 读取锚点；移除“过严导演 Command 锁存”路线；Hook 数 4 -> 5。
- v0.5 -> v0.6：新增消息选择 UI 状态机、Scene runtime +0x280、BattleManager vptr/vtable[1] 三个机器码锚点；剧情改“锁存”，Battle 纳入中央640电影式；模糊强度按实机反馈提高。
- v0.6 -> v0.7：新增 world manager -> 消息更新/绘制两条 CALL 锚点（0x0040b087 -> 0x00403e30、0x0040b08c -> 0x00404800）；对白分类简化为玩家/非玩家二分；侧画消息隔离落地。
- v0.7 -> v0.8：侧区动画由整块 alpha 淡化改为按空间宽度从两侧推入/退出，并带边缘柔化带。
- v0.8 -> v0.9：删除玩家/非玩家视觉分类，任意消息 UI 统一触发电影式侧区；引入 INI（[Transition] 250/250ms，Win32 Profile API，真实毫秒计时）；不再改写主动交互 Event CALL。
- v0.9 -> v0.10：新增 16:9/21:9 双几何（107/240 侧宽、982/1248 staging、214/280 模糊宽度）与 Ultrawide 开关（默认关闭，保持16:9）；小地图对称居中策略；INI 增加 [Display]。
- v0.10 -> v0.11：消息 UI 统一触发改为“侧面板模式”；新增模糊/纯黑两种侧区样式分支（纯黑模式可跳过模糊背景生成，两种样式共享推入/退出与边缘柔化路径）；INI 新增 [Cinematic]（默认保持电影式模糊侧区）；源码读取显示模式、侧区样式与进入/退出时间。
