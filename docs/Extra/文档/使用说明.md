# 《幽城幻剑录》功能拆分 ASI v0.3.2 使用说明

> **重要：不要继续使用先前的 v0.3.1 完整包预编译 ASI。** 后续专项审计发现该包四个正式 ASI 的 PE `AddressOfEntryPoint` 都是 0，正常 Loader 不会调用 `DllMain`。v0.3.1a 已重新链接并逐个验证非零入口点；v0.3.2 继续继承这一构建硬门。

## 1. 当前正式插件

把需要的 `.asi` 放到 `RPG.exe` 的 ASI Loader 可加载目录即可。

- `BUGFix.asi`：固定启用三组原版 BUG 修复，无 INI；除“冥狱杀阵/抗性”外，已合并稳定 CrashFix test2 的“读档→返回标题→新游戏”Legacy Background Controller 双调用路径崩溃修复；日志 `BUGFix.log`。
- `AnytimeSave.asi`：安全扩展存档，无 INI；日志 `AnytimeSave.log`。
- `NoCD.asi`：免 CD，无 INI；日志 `NoCD.log`。
- `MaxGrowthAndDrop.asi`：最大成长 + 最大掉宝；配置 `MaxGrowthAndDrop.ini`；日志 `MaxGrowthAndDrop.log`。

所有正式插件日志均：

- 每次启动先清空旧日志；
- UTF-8（带 BOM）；
- CRLF；
- 简体中文。

源码构建入口现已彻底拆开：`src/Extra/BUGFix/build.bat`、`src/Extra/NoCD/build.bat`、`src/Extra/MaxGrowthAndDrop/build.bat` 可以分别单独构建对应功能；`src/Extra` 根目录不再保留构建脚本；`src/SaveEnhance/build.bat` 单独构建 `AnytimeSave.asi`。根 `build_all.bat` 会直接调用这四个独立入口；此目录变化不影响游戏中的安装方式。

## 1.1 CrashFix 已并入 BUGFix

从 v0.3.2 起，不再需要单独部署 `CrashFix.asi`，也不需要 `CrashFix.ini`。

用户已经确认 CrashFix v0.1.0-test2 双调用路径方案运行稳定，因此其核心修复固定并入 `BUGFix.asi`，和其它原版 BUG 修复一样默认生效、没有开关。

**不要同时加载旧的独立 `CrashFix.asi` 与 v0.3.2 `BUGFix.asi`。** 两者会尝试接管同一组 `0x00409541 / 0x00409587` 路径；v0.3.2 本身会因机器码已被其它 DLL 改写而 fail-closed，但没有并存的必要。

`BUGFix.log` 启动后应至少报告：

- “冥狱杀阵可被习得”修复已生效；
- 抗性错位修复已生效；
- Crash 双调用路径 Route A / Route B 已安装。

真正经过 Route A / Route B 时，日志还会记录首次路径观察；检测到 stale controller 时记录 Crash 命中与清理。

## 2. AnytimeSave（沿用 v0.3.1a 安全回退算法）的实际含义

本版不再尝试生成 `.TSA` / `.YCS`，也不再尝试“读档回到按下保存键的精确坐标”。

它的目标是：**原版不让存的地方，只要已经取得可靠入口级安全锚点，就允许把当前进度保存成一个原版仍可直接读取的 TSF；读档时位置回到场景入口/早期安全点。**

### 原版本来允许存档

完全交给 RPG.exe 原逻辑，插件不修改 World 快照。

### 原版本来禁止存档

只有当前地图已经在默认 Scene Mode 下稳定运行至少 8 个完整 Map Tick，并冻结了入口级安全锚点，才开放存档。

写盘时：

1. 临时备份当前 200-byte World 场景恢复头；
2. 把入口级安全锚点的 200-byte 场景恢复头临时放给原版 Writer；
3. 调用 RPG.exe 原版 `0x43B360` 生成普通 TSF；
4. Writer 返回后立刻恢复内存。

因此游戏画面里的角色不会因为保存被传送。

## 3. 兼容性

本版：

- 不修改 TSF 格式；
- 不追加 TSF 尾部；
- 不创建任何额外存档文件；
- 不要求没有插件的原版游戏认识新格式。

扩展存档拿到没有插件的原版游戏中，仍然只是普通 TSF。区别是读档位置通常回到本场景入口/早期安全点，而不是扩展保存时的当前位置。

## 4. 已有实机结论

用户已经在磐沙堡楼梯危险区域验证：旧“无条件随时存档”会产生坏档的场景，使用 vanilla fallback 后，同一 TSF 可以正常读档，人物回到场景入口而不是楼梯保存点，原来的楼梯坏档没有复现。

这条结论是 v0.3.1a 正式收缩为“安全回退存档”的核心依据。

## 5. MaxGrowthAndDrop.ini

默认：

```ini
[MaxGrowthAndDrop]
MaxGrowth=1
MaxDrop=1
```

删除 INI 后插件会重新生成默认文件；两项可以分别设为 `0` 关闭。

## 6. 诊断工具

`诊断工具/插件/AnytimeSaveProbe.asi` 是只读研究插件。

**不要与正式 `AnytimeSave.asi` 同时加载。** 两者会竞争同一个正常菜单存档许可 CALL Hook。
