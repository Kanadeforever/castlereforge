# 《幽城幻剑录》v0.3.2 已知限制与风险

2026-08-28 的源码目录拆分没有改变下列功能限制；`AnytimeSave` 的当前源码入口为 `src/AnytimeSave`。

0. **旧 v0.3.1 完整包的预编译 ASI 已作废。** 该包 `AddressOfEntryPoint=0`，正常 Loader 不会执行 `DllMain`。必须使用 v0.3.1a 之后的有效入口版本；当前推荐 v0.3.2。
1. `AnytimeSave.asi` 当前是“安全扩展存档 / 进度保险”，不是精确 Save Anywhere。扩展存档读档位置会回到入口级安全锚点。
2. 只有已经在 default Scene Mode 下连续稳定至少 8 个 Map Tick 并冻结 fallback 的地图，原版禁存点才会扩展开放。
3. 当前安全模型已由一处磐沙堡楼梯危险点实机验证，但不能把单个 PASS 外推为全游戏所有特殊场景都绝对安全。
4. EventVM、wait/continuation、scripted movement、camera transition、Battle transient 仍没有被原 TSF 完整保存；当前安全回退算法的做法是避免把这些瞬态对应的危险位置写入 TSF，而不是恢复它们。
5. fallback 只回退 World 前 200 bytes，不回滚 0xC8 后的 5000 个 GameVar。这样优先保留当前剧情进度，但理论上仍可能存在“当前 GameVar + 入口场景头”组合的新边界，需靠实机继续验证。
6. 如果 Writer 阶段地图身份变化或 World 缓冲无法验证，扩展保存会直接失败。这是故意的安全策略。
7. 旧 3in1/5in1 如果已经把 `0x40A0C0` 改成无条件允许，当前版本会先在内存恢复已知原版 9 字节再安装安全 Hook。未知版本/未知机器码则拒绝安装。
8. TSA/YCS 已从正式实现删除。旧测试目录中若残留历史 `.TSA/.YCS`，当前版本不读取、不写入、也不依赖它们；可自行备份后删除。
9. 战斗中随时存档不在当前完成范围。

10. v0.3.2 已把 CrashFix v0.1.0-test2 的稳定双调用路径修复并入 `BUGFix.asi`。不要再同时加载独立 `CrashFix.asi`；也不再需要 `CrashFix.ini`。
11. 合并 Crash 修复目前只支持当前已确认 `RPG.exe` 基线（SHA-256 `829483...287f`）及其机器码等价状态。`0x004067A0 / 0x00409541 / 0x00409587` 任一签名不匹配时，该 Crash 子修复会独立 fail-closed；不会盲改未知 EXE。
12. Crash 修复只处理已经实机稳定的“读档→返回标题→新游戏”Legacy Background Controller 旧引用问题；此前另一个“启动后很快按 ESC 跳开场动画后假死”的 game2 旁支并未并入，也没有被本版声称修复。
