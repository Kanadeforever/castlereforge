# Castle Pad Support 手柄控制说明

> **refactor42：** 默认进入调查自动聚焦最近目标。确定/取消可切换Xbox或PS布局；默认南键/A确定、东键/B取消，设为1后东键/O确定、南键/X取消。调查、菜单和鼠标左右键跟随语义，RB+ABXY快捷不变。

> 以下以 Xbox 手柄的按键名称为准。其它 SDL3 支持的手柄按照对应位置的按键使用即可。

## 按键一览

| 按键               | 主要功能                                   |
| ---------------- | -------------------------------------- |
| **左摇杆**          | 自由地图移动；探索模式下选择可交互目标；<br>部分菜单左右切换角色；鼠标模式下快速移动鼠标|
| **右摇杆**          | 鼠标模式下精细移动鼠标；<br>普通手柄模式下不操作鼠标|
| **方向键**          | 菜单导航；自由地图八方向步行；<br>道具列表上下选择、翻页、目标选择等；<br>战斗中的逃跑/查看属性快捷键（按住RB+上逃跑/下查看属性）|
| **A（南键）**    | Swap=0时确定；Swap=1时取消。<br>RB+A仍固定为攻击，不受Swap影响|
| **B（东键）**    | Swap=0时取消；Swap=1时确定。<br>RB+B仍固定为道具，不受Swap影响|
| **X**            | 当前界面的特殊操作；<br>例如切换装备部位、选择要加点的五内属性、<br>道具分发/弃置、商店买卖切换等；<br>战斗中的技能快捷键（按住RB）|
| **Y**            | 自由地图打开主界面；<br>部分界面的特殊操作（如确认五内加点、商店切换物品说明）<br>战斗中的防御快捷键（按住RB）|
| **LB / RB**      | 调查中循环上一个 / 下一个互动目标；<br>菜单中切换上 / 下大类；战斗中的快捷键激活（按住RB）|
| **LT**           | `ActivationMode=1`时自由地图按住进入调查；<br>菜单中根据界面用于上一子类、减少数值等|
| **RT**           | 自由地图按住进入**临时鼠标模式**；<br>菜单中根据界面用于下一子类、增加数值等 |
| **Back / View**  | 在任何界面开启 / 关闭**常驻鼠标模式**|
| **Start / Menu** | 影片播放时跳过影片等系统操作|

## 0. 确定/取消布局

```ini
[Controls]
SwapConfirmCancel=0
```

- `0`：Xbox位置，南键/A确定，东键/B取消；
- `1`：PS传统布局，东键/O确定，南键/X取消。

确定/取消语义会影响标题、对话、菜单、确认框、存档、调查和鼠标模式。鼠标模式中确定始终是左键、取消始终是右键。RB+ABXY战斗快捷键、X/Y专属功能、肩键与方向键不受影响。

下文“确定键/取消键”均指当前布局对应的物理键。

---

## 1. 自由地图

### 移动

**左摇杆**用于正常移动。

推动幅度较小时为步行，推动幅度较大时为跑步，推动幅度可在ini中自行调整。

**方向键**同样可以控制角色移动，但固定为步行，并支持八方向：

* 上 / 下 / 左 / 右
* 同时按两个相邻方向可以斜向移动

### 打开主界面

自由地图下按 **Y** 打开游戏主界面。

---

## 2. 鼠标模式

手柄提供两种鼠标模式。

### Back：常驻鼠标模式

在**任何界面**按一次 **Back / View** 即可进入常驻鼠标模式。

进入后：

* **左摇杆**：快速移动鼠标
* **右摇杆**：精细移动鼠标
* **确定键**：鼠标左键
* **取消键**：鼠标右键

再次按 **Back / View** 可退出鼠标模式。

如果是在菜单、对话等 UI 中使用常驻鼠标，结束整套 UI 并重新回到自由地图后，插件也会自动恢复正常手柄操作。

### RT：临时鼠标模式

在**自由地图**中按住 **RT** 可以临时进入鼠标模式。

操作方式相同：

* 左摇杆快速移动鼠标
* 右摇杆精细移动鼠标
* 确定键 = 鼠标左键
* 取消键 = 鼠标右键

松开 **RT** 后立即恢复正常手柄操作。

如果按住 RT 时游戏进入新的菜单、对话或其它 UI，临时鼠标模式会自动结束，避免鼠标操作误触新的界面。

### 鼠标速度

鼠标模式采用双摇杆不同速度：

* **左摇杆：主速度，100%**
* **右摇杆：精细速度，默认 15%**

因此需要快速移动时使用左摇杆，需要精确点击较小按钮时使用右摇杆。

鼠标移动速度均可在ini中自行调整。

---

## 3. 调查模式

调查有两种进入方式，由 `Castle_PadSupport.ini` 控制。

### 默认：按住确定键，松开互动

```ini
[Investigation]
ActivationMode=0
```

这是默认方式：

* 自由地图按住 **确定键**：进入并保持调查；
* 保持确定键时使用左摇杆、LB/RB和右摇杆选择目标；
* 原版确认目标后会短震；
* 在目标已经确认时松开 **确定键**：互动一次并退出；
* 目标仍在探测、没有目标或游戏不在前台时松开确定键：只安全退出，不点击；
* 按住确定键时按 **取消键**：立即取消，不互动。

取消以后，即使先松开取消键、仍一直按着确定键，也不会重新进入。必须先松开确定键，再重新按一次。

### 兼容：按住LT，另按确定键确认

```ini
[Investigation]
ActivationMode=1
```

此时保持R40方式：

* 自由地图按住 **LT**：进入并保持调查；
* 调查中按 **确定键**：确认当前目标；
* 松开 **LT**：退出；
* 取消键不增加新的地图业务。

### 进入时自动聚焦最近目标

```ini
[Investigation]
AutoFocusNearest=1
```

- `1`：默认。每次进入调查时自动尝试聚焦离角色最近的可互动目标；仍需原版确认后才震动/互动；
- `0`：关闭。进入后等待左摇杆、LB/RB或右摇杆手动选择。

自动聚焦后，左摇杆明显转向、按LB/RB或移动右摇杆都可以接管；它不会每帧反复把焦点拉回最近目标。

调查模式用于辅助寻找和操作地图中的可互动目标。

进入后，左摇杆采用**连续方向选择**：第一次推离死区后可以一直保持，不必回中；转动摇杆即可实时切换到对应方向的可互动目标。

调查模式还可以使用：

* **RB**：按角色距离顺序选择下一个互动目标；到最远目标后回到最近目标；
* **LB**：按同一顺序选择上一个互动目标；到最近目标前会回到最远目标；
* 没有当前目标时，第一颗 RB 选择最近目标，第一颗 LB 选择最远目标。

LB/RB 选中后会临时锁住目标，避免仍偏着的左摇杆在下一帧抢回。左摇杆回中，或相对肩键按下时的方向明显转动约12°后，方向轮盘重新取得控制；若按肩键时左摇杆本来就在中心，保持回中可以连续按 LB/RB，下一次重新推杆时立即交还左摇杆。

肩键按下本身不会伪造震动。插件把候选交给既有25点探测，只有原版 resolver 真正确认新的互动 hover 后才短震；如果没有目标或尚未确认，不会空震。确认方式由ActivationMode决定。

震动遵循统一的“**实际 hover 到可互动对象才反馈**”规则：A/LT调查、Back常驻鼠标和自由地图RT临时鼠标都一样。进入模式、松开确定键或按取消键本身不会空震；普通手柄状态的隐藏鼠标仍静默。

如果需要精确移动鼠标，可以继续使用右摇杆；右摇杆一旦开始人工精调，松开后不会因为左摇杆仍保持原方向而自动吸回旧目标。左摇杆明显转向新的目标方向后，连续选择会自然恢复。

如果调查中按住 **RT**：

> **RT 临时鼠标模式的优先级高于两种调查模式。**

松开RT后，如果当前配置的调查键仍按住，就恢复调查；若A/LT已经松开，则回普通手柄。RT鼠标中A/B继续是鼠标左右键，因此B不会在RT期间触发调查取消。

## 4. 对话与剧情

### 普通对话

**A** 用于推进对话。

如果当前文字还没有完全显示：

> 第一次按 A 会先让当前文字完整显示。

文字已经全部显示后：

> 再按 A 才会进入下一句。

因此不会因为连续确认而直接跳过尚未看完的文字。

### 是 / 否与选择框

通常使用：

* **方向键**：移动选项
* **A**：确认
* **B**：取消 / 返回

多层剧情选择框同样遵循这一套操作方式。

## 5. 主界面

在自由地图按 **Y** 打开主界面。

### 通用操作

* **LB / RB**：切换上一 / 下一主分类
* **B**：返回上一层或关闭界面
* **左摇杆左右**：在支持的页面切换角色
* **方向键**：操作当前页面中的项目

不同页面会根据原版功能重新分配 X、Y、LT、RT 等按键。

### 道具

* **上 / 下**：选择道具
* **左 / 右**：上一页 / 下一页
* **LT / RT**：切换道具子分类
* **A**：使用 / 确认当前道具
* **X**：分发、弃置等当前允许的特殊操作
* **B**：返回

### 技能

* **上 / 下**：选择技能
* **左 / 右**：翻页
* **LT / RT**：切换技能子分类
* **A**：使用技能
  - 使用治疗技能后，治疗图样的光标会自动聚焦顶部的角色，可用方向键左右导航，按A为选择的对象施法。
* **B**：返回

### 装备

* **X**：循环切换武器 / 防具 / 饰品部位
* **上 / 下**：选择候选装备
* **左 / 右**：翻页
* **LT / RT**：页面快捷切换
* **A**：装备
* **B**：返回
* **左摇杆左右**：切换角色

### 人物属性 / 五内

* **X**：循环切换五内节点
* **LT**：减少
* **RT**：增加
* **Y**：确认“蕴魂”
* **左摇杆左右**：切换角色
* **B**：返回

### 阵型

* **方向键**：移动阵位
* **A**：确认
* **B**：取消当前操作 / 返回

### 天书

* **上 / 下**：选择待使用的存档槽位
* **左 / 右**：翻页
* **A**：打开档案管理选项
  - 注意，此页面按**B**无效，这是漏做的内容，未来更新会修复；

### 系统选项

* **上 / 下**：选择设置项目
* **LT / RT**：降低 / 提高音乐、音效等数值
* **A**：执行当前项目
* **B**：返回

## 操作原则

Castle Pad Support 并不是简单地把手柄按键映射成键盘。

插件会识别游戏当前处于：

**自由地图、对话、选择框、主界面、道具、装备、技能、五内、阵型、系统菜单、商店、合成、客栈、战斗、目标选择、存档等不同状态，**

再调用对应的原版游戏操作。

因此同一个按键在不同界面中可能具有不同作用。

最通用的记忆方式是：

> **A = 确认，B = 返回，方向键 = 导航，LB / RB = 大分类，LT / RT = 子分类或数值调整，Y = 打开主界面，Back = 常驻鼠标。**

自由地图另外记住：

> **LT = 调查，RT = 临时鼠标。**
