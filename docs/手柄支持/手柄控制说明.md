# Castle Pad Support 手柄控制说明

> **refactor39 LT 调查现行手感：** 自由地图按住 LT 后，左摇杆以**当前角色位置**为轮盘中心持续选择可互动目标；不需要回中，持续旋转即可换目标。右摇杆仍做精细鼠标调整。R38 已确认普通隐藏鼠标误震修复，现行震动只在 LT 调查或 Back/RT 鼠标模式真正 hover 新可互动对象时发生。

> 以下以 Xbox 手柄的按键名称为准。其它 SDL3 支持的手柄按照对应位置的按键使用即可。

## 按键一览

| 按键               | 主要功能                                   |
| ---------------- | -------------------------------------- |
| **左摇杆**          | 自由地图移动；探索模式下选择可交互目标；<br>部分菜单左右切换角色；鼠标模式下快速移动鼠标|
| **右摇杆**          | 鼠标模式下精细移动鼠标；<br>普通手柄模式下不操作鼠标|
| **方向键**          | 菜单导航；自由地图八方向步行；<br>道具列表上下选择、翻页、目标选择等；<br>战斗中的逃跑/查看属性快捷键（按住RB+上逃跑/下查看属性）|
| **A**            | 确认、使用、对话推进；<br>鼠标模式下为鼠标左键；<br>战斗中的攻击快捷键（按住RB）|
| **B**            | 取消、返回；<br>鼠标模式下为鼠标右键；<br>战斗中的道具快捷键（按住RB）|
| **X**            | 当前界面的特殊操作；<br>例如切换装备部位、选择要加点的五内属性、<br>道具分发/弃置、商店买卖切换等；<br>战斗中的技能快捷键（按住RB）|
| **Y**            | 自由地图打开主界面；<br>部分界面的特殊操作（如确认五内加点、商店切换物品说明）<br>战斗中的防御快捷键（按住RB）|
| **LB / RB**      | 切换上 / 下大类；战斗中的快捷键激活（按住RB）|
| **LT**           | 自由地图按住进入**调查模式**；<br>菜单中根据界面用于上一子类、减少数值等|
| **RT**           | 自由地图按住进入**临时鼠标模式**；<br>菜单中根据界面用于下一子类、增加数值等 |
| **Back / View**  | 在任何界面开启 / 关闭**常驻鼠标模式**|
| **Start / Menu** | 影片播放时跳过影片等系统操作|

## 1. 自由地图

### 移动

**左摇杆**用于正常移动。

推动幅度较小时为步行，推动幅度较大时为跑步，推动幅度可在ini中自行调整。

**方向键**同样可以控制角色移动，但固定为步行，并支持八方向：

* 上 / 下 / 左 / 右
* 同时按两个相邻方向可以斜向移动

### 打开主界面

自由地图下按 **Y** 打开游戏主界面。

---

## 2. 鼠标模式

手柄提供两种鼠标模式。

### Back：常驻鼠标模式

在**任何界面**按一次 **Back / View** 即可进入常驻鼠标模式。

进入后：

* **左摇杆**：快速移动鼠标
* **右摇杆**：精细移动鼠标
* **A**：鼠标左键
* **B**：鼠标右键

再次按 **Back / View** 可退出鼠标模式。

如果是在菜单、对话等 UI 中使用常驻鼠标，结束整套 UI 并重新回到自由地图后，插件也会自动恢复正常手柄操作。

### RT：临时鼠标模式

在**自由地图**中按住 **RT** 可以临时进入鼠标模式。

操作方式相同：

* 左摇杆快速移动鼠标
* 右摇杆精细移动鼠标
* A = 鼠标左键
* B = 鼠标右键

松开 **RT** 后立即恢复正常手柄操作。

如果按住 RT 时游戏进入新的菜单、对话或其它 UI，临时鼠标模式会自动结束，避免鼠标操作误触新的界面。

### 鼠标速度

鼠标模式采用双摇杆不同速度：

* **左摇杆：主速度，100%**
* **右摇杆：精细速度，默认 15%**

因此需要快速移动时使用左摇杆，需要精确点击较小按钮时使用右摇杆。

鼠标移动速度均可在ini中自行调整。

---

## 3. 调查模式

在自由地图中**按住 LT**进入调查模式。

调查模式用于辅助寻找和操作地图中的可互动目标。

进入调查模式后，左摇杆采用**连续方向选择**：第一次推离死区后可以一直保持按住，不必回中；只要绕着摇杆改变方向，焦点就会像现代轮盘菜单一样实时切换到该方向更合适的可互动目标。命中可调查对象时会通过手柄震动提供反馈，命中后按下手柄 A 键即可交互。

震动遵循统一的“**实际 hover 到可互动对象才反馈**”规则：LT 调查、Back 常驻鼠标和自由地图 RT 临时鼠标都一样。进入这些模式本身不会因为“鼠标模式”而短震；普通手柄状态下隐藏鼠标即使停在互动对象上也不会震。

松开 **LT** 即可退出调查模式并恢复普通移动。

如果需要精确移动鼠标，可以继续使用右摇杆；右摇杆一旦开始人工精调，松开后不会因为左摇杆仍保持原方向而自动吸回旧目标。左摇杆明显转向新的目标方向后，连续选择会自然恢复。

如果同时涉及 LT 和 RT：

> **RT 临时鼠标模式的优先级高于 LT 调查模式。**

例如已经按住 LT 调查时再按住 RT，会暂时切换到鼠标模式；松开 RT 后，如果 LT 仍然保持按住，则会重新回到调查模式。

---

## 4. 对话与剧情

### 普通对话

**A** 用于推进对话。

如果当前文字还没有完全显示：

> 第一次按 A 会先让当前文字完整显示。

文字已经全部显示后：

> 再按 A 才会进入下一句。

因此不会因为连续确认而直接跳过尚未看完的文字。

### 是 / 否与选择框

通常使用：

* **方向键**：移动选项
* **A**：确认
* **B**：取消 / 返回

多层剧情选择框同样遵循这一套操作方式。

---

## 5. 主界面

在自由地图按 **Y** 打开主界面。

### 通用操作

* **LB / RB**：切换上一 / 下一主分类
* **B**：返回上一层或关闭界面
* **左摇杆左右**：在支持的页面切换角色
* **方向键**：操作当前页面中的项目

不同页面会根据原版功能重新分配 X、Y、LT、RT 等按键。

### 道具

* **上 / 下**：选择道具
* **左 / 右**：上一页 / 下一页
* **LT / RT**：切换道具子分类
* **A**：使用 / 确认当前道具
* **X**：分发、弃置等当前允许的特殊操作
* **B**：返回

### 技能

* **上 / 下**：选择技能
* **左 / 右**：翻页
* **LT / RT**：切换技能子分类
* **A**：使用技能
  - 使用治疗技能后，治疗图样的光标会自动聚焦顶部的角色，可用方向键左右导航，按A为选择的对象施法。
* **B**：返回

### 装备

* **X**：循环切换武器 / 防具 / 饰品部位
* **上 / 下**：选择候选装备
* **左 / 右**：翻页
* **LT / RT**：页面快捷切换
* **A**：装备
* **B**：返回
* **左摇杆左右**：切换角色

### 人物属性 / 五内

* **X**：循环切换五内节点
* **LT**：减少
* **RT**：增加
* **Y**：确认“蕴魂”
* **左摇杆左右**：切换角色
* **B**：返回

### 阵型

* **方向键**：移动阵位
* **A**：确认
* **B**：取消当前操作 / 返回

### 天书

* **上 / 下**：选择待使用的存档槽位
* **左 / 右**：翻页
* **A**：打开档案管理选项
  - 注意，此页面按**B**无效，这是漏做的内容，未来更新会修复；

### 系统选项

* **上 / 下**：选择设置项目
* **LT / RT**：降低 / 提高音乐、音效等数值
* **A**：执行当前项目
* **B**：返回

## 6. 战斗

手柄直接操作原版战斗菜单，不需要使用鼠标。

### 战斗主菜单

* **上 / 下**：选择战斗命令
* **A**：确认

### 技能、道具等列表

* **上 / 下**：选择项目
* **左 / 右**：翻页
* **A**：确认 / 使用
* **B**：返回上一层

部分战斗界面还会根据当前状态使用 **LB / RB** 或 RB 组合快捷操作。

### 目标选择

* **方向键**：切换目标
* **A**：确认目标
* **B**：取消并返回

### 战斗确认框

* **方向键**：选择
* **A**：确认
* **B**：取消

### 战斗结算

按 **A** 继续。

### 战斗快捷键

> 快捷键为按住RB激活。

* **上**：逃跑
* **下**：查看角色属性
* **A**：攻击
* **B**：物品/道具
* **X**：法术/技能
* **Y**：防御

## 7. 商店

### 买卖主界面

* **X**：切换购买 / 出售
* **Y**：显示 / 关闭当前物品资料
* **上 / 下**：选择物品
* **左 / 右**：上一页 / 下一页
* **LB / RB**：切换待出售物品的分类
* **A**：购买 / 出售
* **B**：退出

### 数量选择

* **LT**：减少数量
* **RT**：增加数量
* **左 / 右**：选择确认 / 取消
* **A**：执行当前选项
* **B**：取消

物品资料窗口打开时，按 **Y** 关闭。

## 8. 合成

第一层：

* **上 / 下**：选择项目
* **左 / 右**：翻页
* **LB / RB**：切换分类
* **A**：进入下一层
* **B**：在允许退出的位置返回

第二层：

* **上 / 下**：选择项目
* **左 / 右**：翻页
* **LB / RB**：切换分类
* **A**：确认当前项目
* **B**：返回第一层

## 9. 客栈

客栈界面主要使用：

* **上 / 下**：移动当前选择
* **A**：执行“诸态”“炼化”等当前项目

客栈根界面本身没有额外的 B 返回业务，因此 B 不会被强行映射成不存在的原版功能。

## 10. 标题、存档与影片

### 标题界面

* **方向键**：移动选项
* **A**：确认
* **B**：在当前界面允许时取消 / 返回

### 存档槽

使用方向键移动存档位置，并通过 **A / B** 完成确认或返回。

### 影片

播放游戏影片时：

**Start / Menu** 等价于原版的 ESC 操作，可用于跳过 / 关闭当前影片。

## 操作原则

Castle Pad Support 并不是简单地把手柄按键映射成键盘。

插件会识别游戏当前处于：

**自由地图、对话、选择框、主界面、道具、装备、技能、五内、阵型、系统菜单、商店、合成、客栈、战斗、目标选择、存档等不同状态，**

再调用对应的原版游戏操作。

因此同一个按键在不同界面中可能具有不同作用。

最通用的记忆方式是：

> **A = 确认，B = 返回，方向键 = 导航，LB / RB = 大分类，LT / RT = 子分类或数值调整，Y = 打开主界面，Back = 常驻鼠标。**

自由地图另外记住：

> **LT = 调查，RT = 临时鼠标。**
