# 《幽城幻剑录》Castle_FPSUnlock v1.3 使用说明

## 1. 目标

本插件的目标不是把游戏逻辑从 20Hz 改成 60Hz，而是：

- 原版 Legacy Logic 继续约 20Hz / 50ms；
- 普通地图世界层额外绘制/Present 到约 60Hz；
- Camera 与当前 Camera-follow 对象只在额外显示帧中使用临时预测坐标；
- EVE WAIT、Battle Tick、AI、RNG、SF2 逻辑倒计时等仍只由原版 20Hz Legacy Tick 推进；
- GUI、菜单、HUD、SF2 等完整 Draw Queue 仍只在原版帧执行一次。

## 2. v1.3 修复什么

v1.2 实机日志：

```text
LegacyFrame=223
ExtraPresent=0
无world跳过=102
Battle跳过=0
运行态保护跳过=15
等待运动历史=106
```

这说明 v1.2 已能找到普通地图 world，但把“已有两帧运动历史”错误当成了“允许额外 Present”的必要条件，因此补帧仍然没有真正执行。

v1.3 改成：

- world + 安全状态通过时，始终安排 +17ms / +33ms 两次额外帧；
- 没有运动历史时，额外帧先重复当前 world 画面，绝不再退回 20FPS；
- 有历史时再做 Camera/follower Render-only 预测；
- `object + 0x280` 不再当 scene identity；机器码只证明它是 `0x40B050 -> 0x40ADE0` 使用的内部渲染子对象指针；
- 场景连续性改用 Scene World Manager 对象指针；
- follower 换对象时只暂停 follower 插值，不再连 Camera 插值一起清空；
- Camera/follower 状态改在完整 Legacy Frame 返回后采样。

## 4. 安装

把：

```text
Castle_FPSUnlock.asi
Castle_FPSUnlock.ini
```

放到当前 32 位 ASI Loader 会加载的位置。旧版 `Castle_FPSUnlock.asi` 必须替换，不要同时加载多个版本。

启动后生成：

```text
Castle_FPSUnlock.log
```

## 5. 与宽屏补丁共存

v1.3 不改：

```text
0x44A9C6  RenderQueue CALL
0x44A9E6  Present CALL
```

额外帧执行时只读取这两个 CALL 当前目标，所以：

- 无宽屏时进入原版 Render/Present；
- 宽屏先加载时进入宽屏当前 Hook；
- FPSUnlock 先加载时不会占用宽屏需要改写的机器码。

因此不应再出现 v1.0 的加载顺序冲突。

## 6. GUI 为什么不会再被提频

完整 Draw Queue 仍只执行一次。FPSUnlock 在原版消费队列前扫描混合队列，只复制：

```text
Scene World Manager
vtable[1] = 0x40B050
```

到自己的 world-only synthetic queue。GUI、SF2、HUD、菜单、光标等即使存在于原始队列，也不会被复制，所以 v1.0 的 GUI 闪烁频率翻倍路线不会恢复。

BattleManager：

```text
draw = 0x4429F0
```

出现时主动保持原版 20Hz。

## 7. 配置

```ini
[FrameRate]
Enable=1
TargetFPS=60
LogStats=1

[Interpolation]
MaxPredictionStep=96
```

当前正式实现固定目标 60FPS。

`MaxPredictionStep` 用于防止传送/切图时错误外推。单个真实 20Hz Tick 位移超过该值时，该轴直接使用当前真实值。

## 8. 日志重点

v1.3 统计：

```text
[统计] LegacyFrame=...，ExtraPresent=...，无world跳过=...，Battle跳过=...，运行态保护跳过=...，无插值历史但仍补帧=...
```

普通地图自由探索时第一优先看：

```text
ExtraPresent
```

它必须增长。理想情况下每个 LegacyFrame 附近增加两次额外 Present，因此稳态应接近：

```text
20Hz 原版 Present + 40Hz ExtraPresent ≈ 60FPS
```

`无插值历史但仍补帧` 可以增长，但它现在只表示“该组额外帧暂时没有 Camera 预测”，不会阻止 `ExtraPresent`。

## 9. 当前成功标准

第一阶段：

- 普通探索外部 FPS 明显高于 20；
- `ExtraPresent` 持续增长。

第二阶段：

- Camera 过渡明显顺滑；
- 玩家移动视觉明显顺滑；
- GUI 闪烁速度不变；
- Battle/EVE/动画逻辑速度不变；
- 宽屏正常共存。

详细测试见《实机验收说明.md》。
