# fpsunlock_check.py 静态检查工具说明

## 1. 用途

该脚本只读检查 `RPG.exe` 与 `Castle_FPSUnlock.asi`，不会修改文件。

## 2. 用法

```text
python fpsunlock_check.py D:\Game\RPG.exe
python fpsunlock_check.py D:\Game\RPG.exe release\Castle_FPSUnlock.asi
```

## 3. 原版基线

```text
size      = 462848
SHA-256   = 8294839343b1a7845ddae31ed16216b05850efd39a742e5ca7701aadca97287f
Machine   = 0x014C
ImageBase = 0x00400000
```

## 4. 机器码锚点

| VA | 用途 | 原版字节 |
|---|---|---|
| `0x40179C` | WaitMessage 调用 | `FF 15 98 01 46 00` |
| `0x40171C` | Legacy Frame CALL | `E8 4F 92 04 00` |
| `0x44A9BF` | Pre-Draw helper CALL | `E8 DC 76 FB FF` |
| `0x44A970` | Legacy Frame 入口 | `A1 90 F3 46 00 83 EC 34` |
| `0x40B050` | Scene World Draw | `56 8B F1 8A 86 19 02 00` |
| `0x4429F0` | BattleManager Draw | `A0 0C 24 8E 00 53 33 DB` |

动态兼容点：

```text
0x44A9C6 RenderQueue CALL
0x44A9E6 Present CALL
```

只要求仍是 x86 `E8 rel32 CALL`，不要求目标为原版，因为宽屏会合法 Hook 它们。

## 5. ASI 条件

- PE32；
- i386；
- DLL；
- Import Directory = 0；
- IAT Directory = 0；
- Base Relocation 存在。

## 6. v1.3 封包检查

本工具已对用户提供的原版 `RPG.exe.org` 与 v1.3 最终 ASI 执行，全部通过。
