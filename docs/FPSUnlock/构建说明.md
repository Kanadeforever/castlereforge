# Castle_FPSUnlock v1.3 构建说明

## 1. 文件

```text
Castle_FPSUnlock.cpp
Castle_FPSUnlock.ini
build.bat
fpsunlock_check.py
```

源码文件名使用英文，源码内部提供逐步骤中文注释，包括地址用途、Hook 时序、Draw Queue 筛选、Camera/follower 历史、预测、回退和日志。

## 2. 目标

必须编译 Win32/x86，因为 `RPG.exe` 为 i386 PE32。

推荐工具：

- clang-cl
- lld-link

## 3. 一键构建

Windows 下运行：

```text
build.bat
```

输出：

```text
release\Castle_FPSUnlock.asi
release\Castle_FPSUnlock.ini
release\Castle_FPSUnlock.lib
```

游戏只需要 ASI + INI。

## 4. 正式编译参数

```text
clang-cl --target=i686-pc-windows-msvc /nologo /c /O2 /GS- /GR- /Oi- /utf-8 /W4 /WX
```

链接：

```text
lld-link /dll /machine:x86 /nodefaultlib /entry:DllMain@12 /dynamicbase /nxcompat /timestamp:0
```

关键约束：

- `/W4 /WX`：警告即错误；
- `/nodefaultlib`：不依赖 CRT；
- `/timestamp:0`：固定 PE 时间戳，使同源码重复构建可逐字节比较；
- `/dynamicbase /nxcompat`：保留 ASLR/NX PE 标志。

## 5. BAT 编码

`build.bat` 使用 ASCII-only 可执行正文 + CRLF，并以：

```bat
chcp 65001 >nul
```

开头，避免中文 Windows `cmd.exe` 在切换代码页前误解析 UTF-8 多字节源码。

## 6. 静态检查

构建后：

```text
python fpsunlock_check.py <RPG.exe> release\Castle_FPSUnlock.asi
```

检查 EXE 基线、Hook 锚点、Scene World/BattleManager 函数入口、动态 Render/Present CALL 语义，以及 ASI PE32/x86/Import/Relocation 结构。

## 7. v1.3 可重复构建结论

本版本封包前进行了两次独立从零构建，两个 ASI 逐字节一致。

最终 ASI SHA-256 见《文件校验清单.md》。
