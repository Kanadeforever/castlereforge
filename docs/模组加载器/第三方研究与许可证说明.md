# 第三方研究与许可证说明

## Ultimate ASI Loader 思路

`mods\overrides` 借鉴其 `update\`/overload 思路：在文件 API 层重定向读取，不覆盖原游戏文件。本项目没有照搬其完整目录结构。

Overrides 的逻辑本身与 `SetDllDirectoryW` 无直接依赖；dev9 保留该 API 是已实机成功的整体运行环境裁决。

## DirectDraw 兼容层

cnc-ddraw、DDrawCompat、dgVoodoo 等是独立第三方组件，本包不复制、不分发、不替用户选择。

当前项目裁决：

1. dev9 已实机确认台湾繁中转区恢复；
2. dev9 的 cnc-ddraw 使用/截图链作为正式稳定基线；
3. 非 cnc-ddraw wrapper 曾出现 `SetDisplayMode Error!(DDWCreate)`，用户决定不再继续排查，cnc-ddraw 已满足实际需求；
4. 不得为了理论上的“更干净”擅自重构 dev9 已封存的 SetDllDirectory / ddraw Win32 IAT 兼容边界。

Loader 不 Hook `DirectDrawCreate`、`SetDisplayMode` 或 DirectDraw COM 接口。

## Windows RichEdit

INI 编辑器动态使用系统 `Msftedit.dll` / `Riched20.dll`，本包不分发它们。

## RPG.ico

`资源\RPG.ico` 为用户提供的 Launcher 图标资源，构建时嵌入 EXE。

## About 模块

`about.h` / `about.cpp` 为本项目自有源码，不引入第三方库；about4 已加入正文实测高度自适应布局，about5 只把 About 的工具窗口标题栏恢复为普通顶层窗口标题栏；链接点击时仍动态解析系统 `shell32.dll!ShellExecuteW`。
