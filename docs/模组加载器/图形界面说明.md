# 图形界面说明

`v0.3.0-dev9-about5` 继续以已封存 dev9 GUI/运行时为基线；本轮只把 About 从错误的工具窗口标题栏恢复为标准顶层窗口标题栏。about4 的内容自适应布局与 about3 的 INI 自动换行/逻辑行分色实现全部保留。

## 1. 主窗口

- 默认客户区 1024×640 DIP，并且这就是最小客户区；
- 顶部两行操作说明与 Mod 工作区之间有细分隔线；
- 顶部右侧为 `[关于] [设置]`；
- ASI / Overrides 分成两张卡片；
- 复选框启停；
- 拖动把手或名称区域排序；
- 同名 INI 的 ASI 显示“编辑”；
- 磁盘已经缺失的配置项显示“移除”；
- 底部保留重新扫描、计数与启动按钮。

## 2. About

About 不再使用纯文字 MessageBox，而是独立模态窗口。正文和链接数据都来自 `源码\about.cpp`，GUI 只负责排版与点击行为。about4 已通过真实文字高度测量解决正文覆盖问题；about5 进一步移除错误的 `WS_EX_TOOLWINDOW`，让右上角标题栏/关闭按钮与普通 Windows 顶层窗口一致。

链接使用蓝色下划线显示，可通过系统默认浏览器打开。为了保持 Launcher 静态依赖边界，`ShellExecuteW` 在点击时从 `shell32.dll` 动态解析，不静态链接 Shell32。

## 3. 主窗口缩放

`WM_GETMINMAXINFO` 限制最小尺寸；`WM_SIZE` 完成全部子控件布局后，再用 `RedrawWindow(...RDW_ERASE|RDW_ALLCHILDREN|RDW_UPDATENOW)` 同步擦除并重画，用于避免拖动窗口边框时残留旧像素。

## 4. INI 编辑器

使用系统 RichEdit：优先 `Msftedit.dll / RICHEDIT50W`，旧环境回退 `Riched20.dll / RichEdit20W`。正文使用 Consolas 等宽字体。

INI 编辑器继续保留 about3 的关键变化：

- 不启用横向滚动；
- RichEdit 实际布局完成后重新启用按窗口宽度自动换行；
- 每次窗口尺寸变化都重新建立换行宽度；
- 视觉自动折行不写回真实 CR/LF；
- 语法分色和错误定位按真实 CR/LF 逻辑行处理，不被视觉折行干扰；
- 未保存和保存错误使用醒目亮红色状态文字。

具体规则见 `插件INI编辑器说明.md`。
