# 加载器配置文件说明

`mods\CastleModLoader.ini` 只控制 Loader 自身日志：

```ini
[Logging]
ModLoaderLog=1
GameLog=1
```

- `ModLoaderLog=1`：创建/清空 `mods\modloader.log`，记录 Loader、Locale、ASI、Overrides 基础设施；
- `GameLog=1`：进入 RPG.exe 后建立 `mods\game.log`，记录原版游戏 I/O、生命周期和严重异常；
- `0`：关闭对应日志与只为该日志存在的审计行为。

GUI“设置”保存采用同目录临时文件 + `FlushFileBuffers` + 原子替换。

`mods.ini` 与本文件职责不同：它保存 ASI/Overrides 的启停与顺序。主界面 ASI 行的“编辑”只针对 `mods\asi\插件名.ini`，不会改 `CastleModLoader.ini`。

`dev9-about5` 的 About 标题栏修订不会修改 Loader 配置语义；About 正文/链接来自 `源码\about.h` / `源码\about.cpp`。
