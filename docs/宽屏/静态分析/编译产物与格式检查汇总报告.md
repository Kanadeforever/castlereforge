## 8. 结论

1. 各版本 Castle_Widescreen.asi 均为 PE32 / i386 / DLL / 4 sections，ImageBase 恒为 0x10000000，Subsystem 恒为 Windows GUI(2)。
2. Import Directory 在全部版本恒为 0 —— 符合当前 nodefaultlib 最小运行时设计（v0.6 检查结论原文），插件只使用 RPG.exe IAT / GetProcAddress。
3. DllCharacteristics 恒为 0x00540（DYNAMIC_BASE、NX_COMPAT、NO_SEH）；唯一非空目录是 Base Relocation。
4. SizeOfCode 随版本递增（0x3E00 -> 0x4200 -> 0x4600 -> 0x4E00），与功能演进一致；v0.7 起 SizeOfImage 稳定在 0xA000；v0.11 未导出 PE 头，仅记录体积 size=28672（0x7000），与演进趋势一致。
5. 源码与文档格式规范恒定：C/H/BAT 与 Markdown 为 UTF-8 BOM + CRLF，INI 为 ASCII + CRLF，Python 检查器为 UTF-8 无 BOM + LF；发布包不携带任何构建中间产物。
