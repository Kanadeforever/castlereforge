## R44兼容性说明

R44刻意没有扩大Public API。SaveAction需求通过“外部插件修改原版Button状态、Controller通用尊重原版状态”完成，不需要共享私有协议。

- `CASTLE_PAD_API_VERSION_1`、`CastlePadApiV1`结构、能力位、枚举与唯一导出全部不变；
- 不公开SaveSlot指针、Button指针、disabled字段、焦点或pending；
- 不增加外部输入注入、Consume或UI所有权写接口；
- 外部插件无需固定加载顺序，也无需知道PadSupport内部SaveAction实现。

未来若确需可写服务，应另行设计API v2，不能重解释v1；本轮不提前承诺具体接口。

## R43兼容性说明

R43没有增加API v2，也没有改变 `CastlePadApiV1` 的字段顺序、大小、调用约定或枚举值。

- 剧情中按住RT后，`GetControlMode()` 返回2，`AllowsExternalUiInput()`返回0；
- Back常驻鼠标不再因剧情/菜单结束自动回到0；只有明确退出或实体鼠标接管才变化；

- 删除普通活动自动隐藏路径不改变物理按钮、轴或语义动作快照。

# Castle PadSupport Public API v1

## 1. 目的

`CastlePad_GetApi` 是 `Castle_PadSupport.asi` 面向所有第三方 ASI 的稳定只读接口，不是 Backlog 私有协议。
第三方不需要链接 PadSupport 的 `.lib`，也不需要知道 SDL3、`PadInputState`、`InputRouter` 或 `ControlModeState` 的内部布局。

## 2. 获取接口

```c
HMODULE module = GetModuleHandleA("Castle_PadSupport.asi");
CastlePadGetApiFn get_api =
    module ? (CastlePadGetApiFn)GetProcAddress(module, "CastlePad_GetApi") : NULL;
const CastlePadApiV1* api =
    get_api ? get_api(CASTLE_PAD_API_VERSION_1) : NULL;
```

调用方必须检查：
- `magic == CASTLE_PAD_API_MAGIC`；
- `api_version == CASTLE_PAD_API_VERSION_1`；
- `struct_size >= sizeof(CastlePadApiV1)`；
- 所需 `capability_flags`；
- 自己将调用的函数指针非空。

## 3. Public API v1 能力

### 物理输入
- `ButtonDown / ButtonPressed / ButtonReleased`
- `GetAxis`
- `IsReady / IsConnected / GameForeground`

### 语义输入
- `ActionDown / ActionPressed / ActionReleased`
- `CONFIRM/CANCEL` 自动遵守 PadSupport 的 `Controls.SwapConfirmCancel`

### 控制模式
`GetControlMode()` 稳定编号：
- `0`：普通手柄；
- `1`：Back 常驻鼠标；
- `2`：RT 临时鼠标；
- `3`：调查模式；
- `0x7FFFFFFF`：未知。

普通外部 UI 应优先使用 `AllowsExternalUiInput()`；只有 PadSupport ready、手柄连接、游戏前台且处于普通手柄模式时才返回 1。

## 4. 线程模型

PadSupport worker 每个输入 tick 在 `PadInput_Poll -> InputRouter_BeginFrame -> ControlModes_Update`
完成后，把按钮、轴、语义动作和模式复制进只读快照。外部线程只读快照。

因此第三方：
- 不直接读 `g_pad/g_modes`；
- 不调用 SDL3；
- 不修改 consumed mask；
- 不改变 PadSupport 模式机。

## 5. ABI 版本规则

v1 已发布字段顺序、类型和语义永久保持。
未来新增能力使用 v2 或在兼容规则下扩展，不允许重解释 v1。

## 6. x86 导出规则

源码使用 `Castle_PadSupport.def`：

```def
LIBRARY Castle_PadSupport
EXPORTS
    CastlePad_GetApi
```

**不要写 `CastlePad_GetApi=_CastlePad_GetApi`。**
在 x86 MSVC/lld-link 下该别名会被再次装饰为 `__CastlePad_GetApi`；裸导出名会正确解析内部 C 符号并生成未修饰 PE export `CastlePad_GetApi`。
