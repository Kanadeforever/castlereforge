## 4. R41机械护栏

- Runtime必须以默认0、范围0..1读取ActivationMode；
- ControlModes必须集中提供调查键pressed/down/released/inhibited，禁止散落 `lt_pressed/lt_down`；
- A调查顺序必须为B取消→RT覆盖→A松开；
- B取消必须武装释放屏障并完整清probe/点击；持续A直到物理松开都不能重进；
- A松开确认必须先active、前台、无pending、新鲜快照、真实hover，最后才PulseLeftClick；
- A成功松开确认后只能EndSession，禁止ResetClicks抹掉已获准脉冲；
- 旧A按下确认必须由 `ActivationMode==1` 硬门保护；
- RT恢复必须共用当前调查键语义；A模式恢复时撤销临时confirm残留屏障；
- A/B按下松开本身不空震；仍只在resolver确认新hover后短震；
- R40左杆/LB/RB/右杆、25点probe、普通隐藏鼠标静默和RPG地址继续受旧护栏保护。
