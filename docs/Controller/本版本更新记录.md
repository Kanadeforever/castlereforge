## 2. 五内：修复“逻辑焦点变了但鼠标没动”

r23 的业务隔离方向没有推翻：`0x44066E -> 0x431400` 与无 pending `0x4406A8 -> 0x431380` 仍用于隔离“合成视觉鼠标”和“真实鼠标业务”。

真正的新根因来自 Button 几何：

- r23 直接读取 `Button+0x3C/+0x40`；
- 只要宽或高 `<=0` 就判几何失败；
- 但原版 `0x431310` 明确规定，override 为 0 时去 Sprite 当前 frame 取得真实尺寸；
- 因此 X 已切换 `node_index`，`inner_show_node_focus()` 却可能拿不到坐标而提前退出。

r24 新增 UI 基础能力：

- `UiBridge_GetButtonScreenRect()`：完整复刻 `0x431310` 的左上角 + override/Sprite fallback；
- `UiBridge_GetButtonScreenCenter()`：在同一可靠矩形上计算中心；

五内 X 顺序、←/→减加、Y蕴魂及两层业务隔离保持不变。

## 3. shared SpatialNeighbor：删除 r23 的严格 45° 扇区

r23 规则：

- 左右要求 `|dx| >= |dy|`；
- 上下要求 `|dy| > |dx|`。

对错列/斜排布局，这会直接排除真实邻居，是阵形 ↑/↓ 无效和 Battle Target 回归的共同原因之一。

r24 规则恢复为：

- ←：`dx < 0`；→：`dx > 0`；↑：`dy < 0`；↓：`dy > 0`；
- 左右优先最小 `|dy|`，再最小 `|dx|`；
- 上下优先最小 `|dx|`，再最小 `|dy|`。

这与 r22 Battle 的成熟真实屏幕方向原则一致，同时可被阵形安全复用。
