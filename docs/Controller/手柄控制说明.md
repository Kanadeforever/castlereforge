> 当前版本：v0.3-refactor44。SaveAction会跳过原版disabled项；天书根槽位层取消键现可退出整个主菜单；R43功能保持。

## 0. 确定/取消布局

```ini
[Controls]
SwapConfirmCancel=0
```

- `0`：Xbox位置，南键/A确定，东键/B取消；
- `1`：PS传统布局，东键/O确定，南键/X取消。

确定/取消语义会影响标题、对话、菜单、确认框、存档、调查和鼠标模式。鼠标模式中确定始终是左键、取消始终是右键。RB+ABXY战斗快捷键、X/Y专属功能、肩键与方向键不受影响。

下文“确定键/取消键”均指当前布局对应的物理键。

## 1. 游戏场景中

### 移动

**左摇杆**用于正常移动。

推动幅度较小时为步行，推动幅度较大时为跑步，推动幅度可在ini中自行调整。

**方向键**同样可以控制角色移动，但固定为步行，并支持八方向：

* 上 / 下 / 左 / 右
* 同时按两个相邻方向可以斜向移动

### 打开主界面

游戏场景中下按 **Y** 打开游戏主界面。

## 2. 鼠标模式

手柄提供两种鼠标模式。

### Back：常驻鼠标模式

在**任何界面**按一次 **Back / View** 即可进入常驻鼠标模式。

进入后：

* **左摇杆**：快速移动鼠标
* **右摇杆**：精细移动鼠标
* **确定键**：鼠标左键
* **取消键**：鼠标右键

再次按 **Back / View** 可退出鼠标模式。

剧情或菜单结束后，常驻鼠标仍继续保持。只有再次按 **Back / View**、在自由地图按RT、实体鼠标接管、游戏失去前台或手柄断开才会结束。

### RT：临时鼠标模式

在**自由地图或剧情消息中**按住 **RT** 可以临时进入鼠标模式。剧情消息包括普通对白、纵向多行选项和“是/否”。

操作方式相同：

* 左摇杆快速移动鼠标
* 右摇杆精细移动鼠标
* 确定键 = 鼠标左键
* 取消键 = 鼠标右键

松开 **RT** 后立即恢复正常手柄操作。

剧情继续播放或进入剧情选项时，RT鼠标保持。若进入标题、战斗、主界面、商店等非剧情UI，临时鼠标模式会自动结束，避免抢走页面自己的RT业务。

### 鼠标速度

鼠标模式采用双摇杆不同速度：

* **左摇杆：主速度，100%**
* **右摇杆：精细速度，默认 15%**

因此需要快速移动时使用左摇杆，需要精确点击较小按钮时使用右摇杆。

鼠标移动速度均可在ini中自行调整。

## 3. 调查模式

调查有两种进入方式，由 `Castle_PadSupport.ini` 控制。

### 默认：按住确定键，松开互动

```ini
[Investigation]
ActivationMode=0
```

这是默认方式：

* 游戏场景中按住 **确定键**：进入并保持调查；
* 保持按住确定键时移动左摇杆，或是按下LB/RB选择调查目标；
* 切换到目标后会短震以提醒目标已选择；
* 在选择好目标后松开 **确定键**：与选择的目标互动一次并退出调查模式；
* 目标仍在探测、没有目标或游戏不在前台时松开确定键：只安全退出，不点击；
* 按住确定键时按 **取消键**：立即取消，不互动。

取消以后，即使先松开取消键、仍一直按着确定键，也不会重新进入。必须先松开确定键，再重新按一次。

### 兼容：按住LT，另按确定键确认

```ini
[Investigation]
ActivationMode=1
```

此时保持旧互动方式：

* 游戏场景中按住 **LT**：进入并保持调查；
* 调查中按 **LB/RB或移动左摇杆**：选择调查目标；
* 调查中按 **确定键**：确认当前目标；
* 松开 **LT**：退出；
* 取消键不增加新的地图业务。

### 进入时自动聚焦最近目标

```ini
[Investigation]
AutoFocusNearest=1
```

- `1`：默认。每次进入调查时自动尝试聚焦离角色最近的可互动目标；仍需原版确认后才震动/互动；
- `0`：关闭。进入后等待左摇杆、LB/RB或右摇杆手动选择。

自动聚焦后，左摇杆明显转向、按LB/RB或移动右摇杆都可以接管；它不会每帧反复把焦点拉回最近目标。

调查模式用于辅助寻找和操作地图中的可互动目标。

进入后，左摇杆采用**连续方向选择**：第一次推离死区后可以一直保持，不必回中；转动摇杆即可实时切换到对应方向的可互动目标。

调查模式还可以使用：

* **RB**：按角色距离顺序选择下一个互动目标；到最远目标后回到最近目标；
* **LB**：按同一顺序选择上一个互动目标；到最近目标前会回到最远目标；
* 没有当前目标时，第一颗 RB 选择最近目标，第一颗 LB 选择最远目标。

LB/RB 选中后会临时锁住目标，避免仍偏着的左摇杆在下一帧抢回。左摇杆回中，或相对肩键按下时的方向明显转动约12°后，方向轮盘重新取得控制；若按肩键时左摇杆本来就在中心，保持回中可以连续按 LB/RB，下一次重新推杆时立即交还左摇杆。

肩键按下本身不会伪造震动。插件把候选交给既有25点探测，只有原版 resolver 真正确认新的互动 hover 后才短震；如果没有目标或尚未确认，不会空震。确认方式由ActivationMode决定。

震动遵循统一的“**实际 hover 到可互动对象才反馈**”规则：A/LT调查、Back常驻鼠标和游戏场景中RT临时鼠标都一样。进入模式、松开确定键或按取消键本身不会空震；普通手柄状态的隐藏鼠标仍静默。

如果需要精确移动鼠标，可以继续使用右摇杆；右摇杆一旦开始人工精调，松开后不会因为左摇杆仍保持原方向而自动吸回旧目标。左摇杆明显转向新的目标方向后，连续选择会自然恢复。

如果调查中按住 **RT**：

> **RT 临时鼠标模式的优先级高于两种调查模式。**

松开RT后，如果当前配置的调查键仍按住，就恢复调查；若A/LT已经松开，则回普通手柄。RT鼠标中A/B继续是鼠标左右键，因此B不会在RT期间触发调查取消。

## 4. 对话与剧情

### 普通对话

**确定键**用于推进对话。

如果当前文字还没有完全显示：

> 第一次按确定键会先让当前文字完整显示。

文字已经全部显示后：

> 再按确定键才会进入下一句。

因此不会因为连续确认而直接跳过尚未看完的文字。

### 纵向多行回答

截图中“我的回答是”属于原版mode=2：

* **上 / 下**：移动原版橙色高亮和手形焦点；
* **确定键**：提交当前项；
* **取消键**：不选择，只阻止按键穿透。

插件不会显示第二只鼠标指针，剧情结果仍由游戏原版提交。

### 是 / 否

通常使用：

* **方向键**：移动选项
* **确定键**：确认当前项
* **取消键**：直接选择“否”

两种剧情选项都可以按住RT临时使用鼠标。

## 5. 主界面

在游戏场景中按 **Y** 打开主界面。

### 通用操作

* **LB / RB**：切换上一 / 下一主分类
* **B**：返回上一层或关闭界面
* **左摇杆左右**：在支持的页面切换角色
* **方向键**：操作当前页面中的项目

不同页面会根据原版功能重新分配 X、Y、LT、RT 等按键。

### 道具

* **上 / 下**：选择道具
* **左 / 右**：上一页 / 下一页
* **LT / RT**：切换道具子分类
* **A**：使用 / 确认当前道具
* **X**：分发、弃置等当前允许的特殊操作
* **B**：返回

### 技能

* **上 / 下**：选择技能
* **左 / 右**：翻页
* **LT / RT**：切换技能子分类
* **A**：使用技能
  - 使用治疗技能后，治疗图样的光标会自动聚焦顶部的角色，可用方向键左右导航，按A为选择的对象施法。
* **B**：返回

### 装备

* **X**：循环切换武器 / 防具 / 饰品部位
* **上 / 下**：选择候选装备
* **左 / 右**：翻页
* **LT / RT**：页面快捷切换
* **A**：装备
* **B**：返回
* **左摇杆左右**：切换角色

### 人物属性 / 五内

* **X**：循环切换五内节点
* **LT**：减少
* **RT**：增加
* **Y**：确认“蕴魂”
* **左摇杆左右**：切换角色
* **B**：返回

### 阵型

* **方向键**：移动阵位
* **A**：确认
* **B**：取消当前操作 / 返回

### 天书

* **上 / 下**：选择待使用的存档槽位
* **左 / 右**：翻页
* **A**：打开档案管理选项
* **取消键**：在天书根槽位层退出整个主界面并返回地图
* 三项动作窗口中：**上 / 下**在可用的“存档/读档/取消”之间移动，**确定键**执行当前项，**取消键**执行原版取消。
* 原版标为disabled的动作不会获得高亮，也会被方向键自动跳过；普通槽三个动作都可用时仍默认“存档”。

注意：只有根槽位层的取消键退出整个主界面。进入三项动作或确认框后，取消键只处理当前子窗口，不会穿透退出主菜单。

### 系统选项

* **上 / 下**：选择设置项目
* **LT / RT**：降低 / 提高音乐、音效等数值
* **A**：执行当前项目
* **B**：返回

## 10. 标题、存档与影片

### 标题界面

* **方向键**：移动选项
* **A**：确认
* **B**：在当前界面允许时取消 / 返回

### 存档槽

使用方向键移动存档位置，并通过 **A / B** 完成确认或返回。

打开“存档/读档/取消”三项窗口后，手柄只在原版当前允许的按钮之间导航：

* 当前项变为disabled时，焦点自动迁到最近的可用项；
* 上/下跳过disabled，不循环；
* 确定键不会执行disabled项；
* 如果三项都不可用，插件停止强制焦点并保留原版鼠标操作。

### 影片

播放游戏影片时：

**Start / Menu** 等价于原版的 ESC 操作，可用于跳过 / 关闭当前影片。

## 操作原则

Castle Pad Support 并不是简单地把手柄按键映射成键盘。

插件会识别游戏当前处于：

**游戏场景中、对话、选择框、主界面、道具、装备、技能、五内、阵型、系统菜单、商店、合成、客栈、战斗、目标选择、存档等不同状态，**

再调用对应的原版游戏操作。

因此同一个按键在不同界面中可能具有不同作用。

最通用的记忆方式是：

> **A = 确认，B = 返回，方向键 = 导航，LB / RB = 大分类，LT / RT = 子分类或数值调整，Y = 打开主界面，Back = 常驻鼠标。**

游戏场景中另外记住：

> **LT = 调查，RT = 临时鼠标。**
