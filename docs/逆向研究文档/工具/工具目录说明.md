# 工具目录说明

> 适用节点：固化68（2026-08-22），现有46项Python工具。以后每次新增、修改或停用工具，都必须同步更新本文和`文档/工具完整使用手册.md`。

## 这个目录放什么

`工具/`只放可执行的Python源码和本说明。机器运行结果必须写入`数据/`，反汇编、资源样本、图片和人工摘录必须写入`证据/`。本次已经把误放在这里的`当前样本验证结果.json`迁到：

`数据/05_资源容器与配置/基础阶段/机器结果/当前样本验证结果.json`

工具继续保持单层平铺，不按主题移动源码。这是有意设计：多项调查器直接导入同目录中的稳定解析器；平铺可以避免改写已验证的Python导入关系。人类按下表找工具，机器仍可直接从同一目录运行。

## 第一次接手时怎么用

1. 先读`文档/截至当前版本的完整接档说明.md`，确认当前Oracle和恢复点。
2. 在本表按研究主题找到调查器。
3. 执行`python 工具名.py --help`读取真实参数，不要从历史聊天猜命令。
4. 输出路径必须显式指向`数据/<主题>/<固化节点>/机器结果`或`表格明细`。
5. 原始机器码、反汇编、图片或资源样本写入对应`证据/<主题>/<固化节点>/<资料类型>`。
6. 执行后同时更新本说明、数据说明、证据说明、完整接档和全文件索引。

## 现行目录整理命令

先预演，不写入：

```text
python 工具/youcheng_research_archive_organizer.py 研究包根目录
```

确认预演中`PASS=true`且“保守兜底分类数”为0后才执行：

```text
python 工具/youcheng_research_archive_organizer.py 研究包根目录 --执行
```

工具会拒绝路径碰撞，不覆盖目标；每个文件移动前后都校验字节数和SHA-256。

## 每次更新的硬性检查

- Python AST解析与内存编译全部通过。
- 每个工具在隔离空目录执行`--help`并以0退出，不生成副作用文件。
- 新工具必须有简体中文注释、明确输入哈希、证据边界和失败退出。
- 本说明的工具数量、分类和依赖必须与目录实物一致。
- `文档/工具完整使用手册.md`必须同步新增详细参数、输出字段和复跑示例。
- 工具不得把结果默认写回`工具/`；所有输出都必须由调用者显式指定到现行`数据/`或`证据/`主题目录。

## 当前边界

工具输出`PASS`只表示该工具声明的断言全部成立，不等于完整游戏行为已经动态证明。负证据、其它版本、间接调用、整体复制和运行时轨迹的边界仍以对应JSON和完整接档为准。
