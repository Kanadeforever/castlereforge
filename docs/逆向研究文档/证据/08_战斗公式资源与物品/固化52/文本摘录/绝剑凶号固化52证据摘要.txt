固化52证据摘要

1. FIRTTECH 真实记录：ID 0x12F（303）=「絕劍凶號」，+0x34=20，+0x38=0，selector(+0x30)=3，K(+0x40)=60。
2. 普通动作落地先平坦扣除 +0x38；随后对 ID 0x12F 显式跳过普通 +0x34 平坦主资源扣除。
3. 0x12F 在 mode2 特殊分派中以 +0x34 乘 main_max，并通过 signed reciprocal 序列形成 -trunc(product/100)，加回 current 即等价于百分比扣除。
4. 百分比扣除后若 main_current<=0，原版强制写回1。
5. 0x421A00 只有 0x421279、0x4212BF、0x4212E0 三个 direct E8 caller；0x12F 特例只在 mode2 分支执行。
6. AI 候选检查仍按 raw +0x34 做平坦 main-current 可支付比较，没有 0x12F 百分比特判。
7. 固化5历史资料中“按比例增加 current”的方向描述是历史错误；固化52以机器码重新确认正确方向为“按最大主资源百分比扣除”。

证据边界：
- “主资源/次资源”是兼容引擎结构称呼，作者正式属性名仍未知。
- 不把 +0x40=60 与 +0x34=20 混为同一参数：前者属于 selector3 公式参数，后者在 0x12F 上被重解释为自身主资源百分比代价。
- 当前 API canonical 资产只能证明现有乘积范围安全，不能推断 MOD/损坏数据永不溢出。
