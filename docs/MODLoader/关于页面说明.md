# 关于页面说明

## 1. 当前实现

`v0.3.0-dev9-about5` 使用 Launcher 自己的独立模态 About 窗口；about3 完成可点击链接化，about4 修复正文高度固定导致的覆盖/截断，about5 再把错误的工具窗口标题栏恢复为普通 Windows 标题栏。

主窗口“设置”左侧保留“关于”按钮。点击后打开独立 About 窗口，窗口内包含：

- 软件名称与版本/说明正文；
- “相关链接”区域；
- 可点击的蓝色下划线链接；
- “关闭”按钮。

About 窗口属于 Launcher GUI，不参与 RPG.exe 的启动、Locale、ASI、Overrides、ddraw 兼容桥或任何游戏进程内 Hook。about4 会用 `DrawTextW(...DT_CALCRECT)` 按真实字体和当前宽度先测量正文高度，再把“相关链接”和底部按钮排在正文之后，因此正常增删几行 About 文字不再需要手工调窗口坐标。


## 2. about4 右上角关闭按钮问题与 about5 修复

about4 创建 About 时使用了 `WS_EX_TOOLWINDOW`。这个扩展风格是给浮动工具条/工具窗口准备的，Windows 会采用工具窗口非客户区，所以实机看到的右上角关闭按钮尺寸和主窗口/设置窗口明显不一致。

about5 删除 `WS_EX_TOOLWINDOW`，About 现在只使用 `WS_EX_CONTROLPARENT`，普通 Style 继续保持 `WS_CAPTION | WS_SYSMENU | WS_CLIPCHILDREN`。因此标题栏和右上角关闭按钮交还给 Windows 按普通顶层窗口规则绘制。About 仍然拥有主窗口 owner，模态关系和任务栏行为不变。

## 3. about3 实机问题与 about4 修复

about3 把正文区域底边和链接区位置按固定高度计算。用户实机截图确认：当前正文在 125% DPI/实际窗口宽度下比预估多折了一行，导致正文末尾被“相关链接”区域直接盖住。

about4 删除这种“预估正文高度”的布局方式：

1. 使用当前 About 窗口的真实 `Segoe UI` 字体；
2. 用 `DrawTextW(..., DT_WORDBREAK | DT_CALCRECT)` 按当前正文宽度测量折行后的真实高度；
3. 正文绘制矩形的 `bottom` 直接使用测量结果；
4. “相关链接”标题从正文真实底部再向下留间距；
5. 链接按钮继续排在标题下面；
6. 顶层 About 窗口在显示前按“正文 + 链接 + footer”重新计算外框高度。

因此以后正常编辑 `about.cpp` 增删几行说明，不再需要同步修改 `launcher_gui.c` 的固定高度。

## 4. 以后主要编辑哪些文件

```text
源码\about.h
源码\about.cpp
```

### `about.cpp`

这是以后最常修改的文件。当前可编辑内容分成三组：

```cpp
static const LPCWSTR kAboutDialogTitle_ = ...;
static const LPCWSTR kAboutDialogText_ = ...;
static const AboutLink_ kAboutLinks_[] = { ... };
```

其中：

- `kAboutDialogTitle_`：About 窗口标题；
- `kAboutDialogText_`：正文；
- `kAboutLinks_`：链接显示名称 + 实际 URL。

添加链接时按现有数组格式追加即可。当前最大显示数量由 `ABOUT_MAX_LINKS` 控制，默认最多 8 项。About 外框高度会根据正文折行高度和链接数量一起重新计算。

### `about.h`

头文件提供稳定 C ABI：

```cpp
LPCWSTR About_GetDialogTitle(void);
LPCWSTR About_GetDialogText(void);
UINT About_GetLinkCount(void);
LPCWSTR About_GetLinkLabel(UINT index);
LPCWSTR About_GetLinkUrl(UINT index);
```

普通的文字、作者、鸣谢、网站链接更新一般只需要改 `about.cpp`；只有想增加新的字段类型或扩大接口时才需要改 `about.h`。

## 5. 链接是怎么打开的

`launcher_gui.c` 不静态链接 `Shell32.lib`。用户实际点击链接时才：

```text
LoadLibraryW("shell32.dll")
  ↓
GetProcAddress("ShellExecuteW")
  ↓
ShellExecuteW(..., "open", URL, ...)
```

这样既能使用系统默认浏览器打开 HTTP/HTTPS 链接，又保持 Launcher 最终 PE 的静态依赖仍只有 `KERNEL32.dll`。

如果系统无法载入 ShellExecute 或链接打开失败，才使用错误 MessageBox 提示；About 主界面本身不再是 MessageBox。

## 6. 字符串编辑规则

- 使用 `L"..."` Unicode 宽字符串；
- 正文换行使用 `\r\n`；
- 相邻 `L"..."` 字符串会在编译时连接；
- URL 也使用宽字符串；
- 不要在 About 模块里加入 STL、iostream、`new/delete` 或游戏 Hook；
- 不要把 Mod Loader 的运行时配置逻辑放进 About。

## 7. 当前默认链接

当前示例/默认链接为：

- Ultimate ASI Loader；
- cnc-ddraw。

这些只是 About 内容，未来可以直接在 `about.cpp` 中增删或替换，不会改变 Loader 功能。
