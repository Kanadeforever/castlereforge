# 架构与启动时序

## 组件

- `CastleModLoader.exe`：GUI + Pre-Loader + INI 编辑器 + About；
- `源码\about.h` / `about.cpp`：只保存 About 文本接口/内容；
- `mods\CastleLocaleBootstrap.dll`：ntdll-only CP950 最早期层；
- `mods\CastleModCore.dll`：Entry Gate、Locale、Overrides、ASI、GameAudit；
- `ddraw.dll`：游戏/第三方图形兼容组件，不属于 Loader 分发物。

## dev9 封存启动时序

```text
CastleModLoader.exe
  ↓ GUI / 配置 / About
CreateProcessW(CREATE_SUSPENDED)
  ↓ Launcher 启动期临时 SetDllDirectoryW(mods)
  ↓ 内存修改 Import Directory
CastleLocaleBootstrap.dll
  ↓ CP950 NLS 最早期准备
CastleModCore.dll
  ↓ Early：读取路径环境、SetDllDirectoryW(mods)、Entry Gate、Locale/Overrides 基础层
Windows Loader 继续初始化 BASS/Bink/ddraw/ijl10...
  ↓
RPG.exe EntryPoint 前 Gate
  ↓ 恢复原入口
再次补挂 RPG/BASS/Bink/ijl10/ddraw/SHLWAPI 的既有 Win32 IAT 桥
  ↓ Locale 文件名实体自检 / 可选 GameAudit
  ↓ ASI：绝对路径 + LOAD_WITH_ALTERED_SEARCH_PATH
RPG.exe 原入口
```

这套运行时已在 dev9 实机恢复转区并正式封版。`dev9-about5` 不改变该时序。

## About 边界

About 在游戏启动前、Launcher GUI 进程内工作：

```text
主窗口“关于”按钮
  ↓
独立 CastleModLoader.AboutWindow
  ↓
About_GetDialogTitle / About_GetDialogText
About_GetLinkCount / Label / Url
  ↓
about.cpp 提供正文与链接数据
  ↓
点击链接时动态解析 shell32.dll!ShellExecuteW
```

About 不读取/修改 Mod 配置，不进入 RPG.exe，不加载 Core，不改变任何 Hook。动态 ShellExecuteW 只用于把用户点击的 URL 交给系统默认浏览器。
