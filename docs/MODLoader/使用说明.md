# 《幽城幻剑录》Mod Loader v0.3.0-dev9-about5 使用说明

> 当前版在 about5 基线上增加 RuntimeSDK 两阶段通知、`mods/logs`、延后 GameAudit Hook 和
> 同名 TOML 编辑器。下文 dev9 封存描述保留业务背景，但配置编辑与日志路径以当前段为准。

## 1. 安装与卸载

把 `build` 中的内容复制到 `RPG.exe` 所在目录：

```text
RPG.exe
CastleModLoader.exe
mods\
├─ CastleLocaleBootstrap.dll
├─ CastleModCore.dll
├─ CastleModLoader.ini
├─ asi\
└─ overrides\
```

两个 Loader 内部 DLL 固定放在 `mods\`，因此卸载仍只需要删除：

```text
CastleModLoader.exe
mods\
```

第三方 `ddraw.dll` 按其自身组件要求部署。当前正式封版基线使用 cnc-ddraw；不再继续排查其它 ddraw wrapper。

## 2. Mod 目录

```text
mods\
├─ CastleLocaleBootstrap.dll   ← Loader 内部组件
├─ CastleModCore.dll           ← Loader 内部组件
├─ CastleModLoader.ini         ← Loader 设置
├─ mods.ini                    ← Mod 启停/顺序
├─ logs\                     ← modloader.log、game.log、Runtime与各ASI业务日志
├─ asi\                      ← .asi、同名 .toml、Castle_Runtime.dll、ASI依赖DLL
└─ overrides\                 ← 文件型 Mod
```

用户 Mod 只进入 `mods\asi` 与 `mods\overrides`。ASI 依赖 DLL 与对应 ASI 一起放 `mods\asi`。

## 3. 主界面

- 复选框：启用/禁用；
- 拖动：调整顺序；
- ASI 从上到下加载；
- Overrides 越靠下优先级越高；
- 有同名 TOML 的 ASI 显示“编辑”；
- 缺失项显示“移除”；
- “重新扫描”重新读取磁盘和配置；
- “启动游戏”进入封存 dev9 启动链。

## 4. About

主窗口顶部右侧：

```text
[关于] [设置]
```

“关于”现在打开独立窗口，支持可点击链接，并会按正文实际折行后的高度自动扩展，避免以后增加文字后与链接区重叠。以后修改内容主要编辑：

```text
source\about.cpp
```

可直接调整标题、正文、作者/鸣谢、网址名称与 URL。接口说明见 `关于页面说明.md`。

## 5. TOML 编辑器

点击有同名 TOML 的 ASI 行右侧“编辑”即可打开。

当前编辑器保留自动换行和逻辑行定位，并改为：

- 注释/节/变量/等号/值分色；
- 按编辑区宽度真正自动换行；
- 不显示横向滚动条；
- 自动换行只影响视觉，不修改真实文件行；
- 未保存与保存错误使用醒目亮红色提示；
- 保存前检查 Runtime TOML v1 标量结构；
- 只接受 UTF-8/UTF-8 BOM并保持 BOM 策略；
- 临时文件 + Flush + 原子替换安全写盘。

## 6. dev9 运行时封存结论

已确认并保持：

- 台湾繁中 / CP950 转区正常；
- cnc-ddraw 满足当前使用需求；
- dev9 正式封版运行时不再擅自清理或重构；
- 非 cnc-ddraw wrapper 的 `SetDisplayMode Error!(DDWCreate)` 调查已停止。

当前 RuntimeSDK 与日志/TOML 增量不改变 Locale、Overrides 和 cnc-ddraw 基线。
