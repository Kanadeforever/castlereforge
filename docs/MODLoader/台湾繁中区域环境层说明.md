# 台湾繁中区域环境层说明

## 目标

让台湾第三版《幽城幻剑录》在不修改系统区域设置的情况下尽早获得 CP950 / zh-TW 运行语义。

## 两层结构

### `mods\CastleLocaleBootstrap.dll`

- 静态依赖严格只有 `ntdll.dll`；
- Early Import 排在 ModCore 前；
- 读取 `c_950.nls` / `l_intl.nls`；
- 使用 Nt/Rtl NLS 原语重建 CP950 表；
- 不扫描 Mod、不写普通日志、不加载 ASI。

### `mods\CastleModCore.dll`

随后建立/确认：

- GetACP / GetOEMCP 950 自检；
- Locale/UI language/台北时区/注册表语言语义；
- USER32 ANSI→Unicode 文本桥；
- GDI `CHINESEBIG5_CHARSET(136)`；
- CP950 ANSI 文件名实体自检；
- Overrides / ASI / GameAudit。

## dev9 封存裁决

dev6～dev8 曾删除 dev5 的部分 `SetDllDirectoryW(mods)` / ddraw Win32 IAT 兼容边界，用户实机 A/B 证明从 dev6 起标题转区与 cnc-ddraw 截图同时回归。dev9 恢复 dev5 运行时边界后，用户确认转区恢复并最终将 dev9 封版。

因此后续版本除非有新的明确实机证据，不得擅自“清理”或重构 dev9 的 Locale/ddraw/SetDllDirectory 运行时链。

`dev9-about5` 只修改 Launcher GUI/About 标题栏；两个运行时 DLL 与 dev9 逐字节一致。
