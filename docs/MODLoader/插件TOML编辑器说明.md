# 插件 TOML 编辑器说明

## 触发条件

只有严格同名组合才显示“编辑”：

```text
mods\asi\插件名.asi
mods\asi\插件名.toml
```

Overrides 不显示编辑按钮。编辑器只编辑已有同名 TOML，不替第三方插件猜配置文件名或业务键。
Loader 自己的 `CastleModLoader.ini` 与 `mods.ini` 不由这个按钮编辑。

## 显示与逻辑行

编辑器使用系统 RichEdit，按窗口宽度自动折行。视觉折行不会向文件插入 CR/LF。分色、错误定位
和行号都按真实 CR/LF 逻辑行计算，窗口缩放不会把长注释误判为多条语法行。

## 颜色

- `#` 注释：绿色；
- `[表]`：紫色；
- 键名：蓝色；
- `=`：灰色；
- 值：橙色；
- 明显错误：亮红色。

行尾 `#` 只有在双引号字符串外才是注释；字符串里的 `#` 保持值内容。

## Runtime TOML v1 检查

同名官方配置当前允许：

- 空行和 `#` 注释；
- 普通 `[表]`，不允许 `[[数组表]]`；
- ASCII 字母、数字、点、下划线、短横线组成的裸键；
- 32 位十进制整数；
- 小写 `true` / `false`；
- 英文双引号字符串，以及 `\n`、`\r`、`\t`、`\\`、`\"` 转义。

编辑器不检查每个插件自己的数值范围；插件仍会用 TOML API 的 minimum/maximum 进行业务夹取。
复杂 Quest 数据库不通过同名配置按钮编辑，因此数组表不属于这个编辑器的 v1 目标。

## 编码

TOML 必须使用 UTF-8。编辑器接受 UTF-8 无 BOM 或 UTF-8 BOM，并在保存时保持是否有 BOM。
ANSI、UTF-16LE、UTF-16BE 明确拒绝，不再沿用旧 INI 的多编码兼容，以免 GUI 保存成功而 Runtime
无法读取。

编辑框内部的 UTF-16 在保存前还会检查代理项配对：扩展汉字等合法代理对可以保存；孤立高/低
代理项会报告真实错误行，并在创建临时文件之前停止，防止 Windows 转码时悄悄替换文字。

## 安全保存

```text
原 TOML
  ↓ 先通过语法检查
同目录 .castle.tmp
  ↓ WriteFile + FlushFileBuffers
MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)
  ↓
替换原 TOML
```

校验、编码、临时写入或原子替换任一步失败，原文件保持不变。编辑器底部显示亮红未保存/错误状态，
详细弹窗会选择到真实逻辑错误行。
