# 工具说明

## `tools\preloader_check.py`

只读结构/回归检查器，只依赖 Python 标准库，不修改 RPG.exe、DLL、INI 或 Mod。

### dev9-about5 重点检查

- About 独立窗口、可点击链接与动态 `ShellExecuteW`；
- INI RichEdit 在真实布局后刷新自动换行；
- 分色/错误定位使用真实 CR/LF 逻辑行，不受视觉折行影响；
- 未保存/保存失败使用亮红状态；
- dev9 运行时源码聚合 SHA 与两个运行时 DLL 不漂移。

- dev9 Early Import、SetDllDirectory、Locale、ddraw Win32 IAT 兼容边界仍保留；
- 两个 Loader DLL 位于 `mods\`，根目录无重复副本；
- ASI 继续使用绝对路径 + `LOAD_WITH_ALTERED_SEARCH_PATH`；
- GUI/INI 编辑器既有行为继续存在；
- 新增 `about.h` / `about.cpp`；
- “关于”按钮位于“设置”左侧；
- About 文本实际进入最终 EXE；
- `build.bat` 会按 C++ 单元编译 `about.cpp` 并链接 `about.obj`；
- 所有影响 RPG.exe 运行时的源码按固定顺序计算聚合 SHA-256，必须与封存 dev9 完全一致；
- 本包随附的两个运行时 DLL 另在“完整接档/当前版本验证证据”中记录为与 dev9 二进制逐字节一致；
- Launcher 最终仍只静态依赖 `KERNEL32.dll`；
- `RPG.ico` 的 RT_ICON / RT_GROUP_ICON 仍存在于最终 EXE。

### 用法

```text
python tools\preloader_check.py
python tools\preloader_check.py "C:\游戏\幽城幻剑录\RPG.exe"
```

第二种还会检查已确认的 RPG.exe SHA-256、PE32、EntryPoint `0x52C19`、入口字节、13 个状态断点机器码和 Early Import 可用空间。

静态 PASS 不能替代 Windows 实机 UI/启动烟雾测试。
