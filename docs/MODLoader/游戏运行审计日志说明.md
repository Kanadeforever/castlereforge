# 游戏运行审计日志说明

`mods\logs\game.log` 只记录原版游戏时间线；`mods\logs\modloader.log` 记录
Loader/Locale/ASI/Overrides 基础设施。

## 原版 caller 白名单

```text
RPG.exe
BASS.dll
binkw32.dll
ijl10.dll
```

`ddraw.dll` 与 `SHLWAPI.dll` 不注册为原版 caller。dev9 虽保留对 ddraw.dll 的既有 Win32 IAT 兼容桥，但 cnc-ddraw 自身截图输出不会冒充 RPG.exe 原版访问写进 `game.log`。

## 13 个状态边界

继续沿用 NEW_GAME / Save / Load / Serializer / Event / Scene 等 13 个机器码已确认位置；每次安装前核对原字节，不匹配则 fail-closed。具体地址见 `截至v0.3.0-dev9-about5的完整接档.md`。

## 异常

VEH 只旁路记录严重异常和 x86 寄存器现场，然后 `EXCEPTION_CONTINUE_SEARCH`，不吞游戏崩溃。

当前 GameAudit 会把 13 个状态 Hook 延后到全部 ASI 初始化之后；若 Runtime 已拥有某个入口，
严格 expected bytes 会使审计点安全跳过，不在 Runtime 之前盲装上游 Hook。
