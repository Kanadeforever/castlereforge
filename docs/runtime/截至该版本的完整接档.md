## 4. 关键冲突结论

### SaveEnhance / Controller

旧版两者都接触 SaveAction。现在 Runtime Save 唯一包装 vtable，SaveEnhance登记 0 和 91～99
禁写策略，Controller 只读原版 disabled。加载顺序不再影响结果。

### Widescreen / FPSUnlock

Runtime Render 唯一拥有 `0x44A9C6/0x44A9E6`。Widescreen 发布后端；FPSUnlock 请求额外帧。
GameState 租约保护 Camera、DrawQueue、Dialogue 和 World 临时变化。

### Quest / Present / Exploration

Quest 的 `0x4064E0` Present 与 `0x409580` 探索入口本地实现已删除。现在使用 Overlay、Schedule
GamePhase、Display 和 GameState。Marker 不复制 CameraPlan。

### 输入联动

Controller 发布 Runtime Input。Backlog 和 SaveEnhance 不再按 PadSupport ASI 文件名直连。
Backlog 还使用 Input Focus 和 Dialogue Mutation Lease。

## 13. 已踩坑

- 无 CRT Runtime 漏入 `_memcpy` 会在链接阶段失败；正式链接必须包含 runtime_crt_support；
- FARPROC 直接强转在 Clang `-Wcast-function-type-mismatch` 下失败，必须位模式复制；
- Runtime 测试 DLL 曾因缺少真实 PE 合同而出现 0xc000012f；现已验证 PE32/入口/依赖；
- Schedule 若在外层 InitializeASI 完成前启动，会让 Backlog/Controller“加载成功但完全不可用”；
- BAT 混合 LF/CRLF 被父脚本 call 时会吞行并产生 `Tfail` 等伪命令；构建脚本统一 CRLF；
- build_all 曾因 FPS/Quest 步骤被跳过而读取旧产物假绿；现在构建前精确清除旧正式文件；
- TOML 初迁移丢失详细注释；当前模板已逐键恢复，并有机械检查；
- ModLoader 编辑器若继续允许 ANSI/UTF-16，会与 Runtime UTF-8 解析边界不一致；现在明确拒绝。
