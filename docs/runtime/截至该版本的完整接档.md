# RuntimeSDK 截至当前版本的完整接档

## 1. 当前结论

Castle Runtime 已从“可选协调层”调整为官方 ASI 必需的基础引擎。官方插件可以脱离 Castle Mod
Loader和其它业务插件，但必须携带同目录 `Castle_Runtime.dll`。缺失或损坏 Runtime 时业务保持
停用，不再回退本地 Hook。

当前代码已完成主要 P0/P1 冲突收口、官方配置 TOML 迁移、统一日志目录和 FPSUnlock/Quest SDK
接入。自动构建与宿主测试已通过；本轮最终全量 build_all 和游戏实机仍需在文档全部同步后再做。

## 2. 已确认部署

```text
build\
├─ CastleModLoader.exe
└─ mods\
   ├─ CastleLocaleBootstrap.dll
   ├─ CastleModCore.dll
   ├─ asi\
   │  ├─ Castle_Runtime.dll
   │  ├─ 正式官方ASI
   │  ├─ 同名TOML
   │  ├─ Castle_Quest\ 任务数据库
   │  └─ Castle_SaveEnhance\ 音效与说明
   └─ logs\
```

Runtime DLL 不由 ModLoader/ASI Loader 直接扫描，由 SDK ASI Client 在 Loader Lock 外加载。

## 4. 关键冲突结论

### SaveEnhance / Controller

旧版两者都接触 SaveAction。现在 Runtime Save 唯一包装 vtable，SaveEnhance登记 0 和 91～99
禁写策略，Controller 只读原版 disabled。加载顺序不再影响结果。

### Widescreen / FPSUnlock

Runtime Render 唯一拥有 `0x44A9C6/0x44A9E6`。Widescreen 发布后端；FPSUnlock 请求额外帧。
GameState 租约保护 Camera、DrawQueue、Dialogue 和 World 临时变化。

### Quest / Present / Exploration

Quest 的 `0x4064E0` Present 与 `0x409580` 探索入口本地实现已删除。现在使用 Overlay、Schedule
GamePhase、Display 和 GameState。Marker 不复制 CameraPlan。

### 输入联动

Controller 发布 Runtime Input。Backlog 和 SaveEnhance 不再按 PadSupport ASI 文件名直连。
Backlog 还使用 Input Focus 和 Dialogue Mutation Lease。

## 5. 配置迁移

以下正式配置已从 INI 改为 TOML：

- Castle_Backlog.toml；
- Castle_PadSupport.toml；
- Castle_Widescreen.toml；
- Castle_SaveEnhance.toml；
- MaxGrowthAndDrop.toml；
- Castle_Quest.toml；
- Castle_FPSUnlock.toml（实验版，单独构建）。

每个键已经恢复并补齐独立中文说明。build_all 主动删除上述插件的同名旧 INI，避免双配置。
ModLoader 的 ASI 配置编辑按钮改为同名 TOML，强制 UTF-8，按 Runtime TOML v1 检查并原子保存。

Loader 自己的 `CastleModLoader.ini` 和 `mods.ini` 保持原样，因为它们在 Runtime 之前生效。

## 6. 日志迁移

Runtime 自己记录 `mods/logs/Castle_Runtime.log`。官方业务插件通过 Log 服务写各自文件。ModLoader
记录 `mods/logs/modloader.log`，游戏审计记录 `mods/logs/game.log`。

官方插件的 ASI 同目录日志旁路已删除；Runtime Fault 回调不创建替代日志。

## 7. 文件与模块迁移

- Controller 的 SDL3 由 Module 从插件相对路径加载并固定驻留；
- SaveEnhance 的 user32/winmm 由 Module 系统白名单加载；
- SaveEnhance 的 WAV 缩放读取由 File 负责；
- 100% 音量时 PlaySoundW 所需绝对路径由 Path 构造；
- MaxGrowthAndDrop 不再自动创建 INI；
- 所有普通插件日志由 Log 写。

保留例外：`multimedia/save/.NEXTAUTOSLOT` 是 SaveEnhance 已验收的三字节历史兼容游标，位于
File v1 根外。当前保持原路径和格式，不把它错误称为 `.state`。

## 8. `.state` 真实状态

当前没有任何插件创建或读取 `SaveXXX.state`。Quest 只规划未来持久化 Addon 完成键；SaveEnhance
当前也只有 `.NEXTAUTOSLOT`。

为了避免空功能新增 Save/Load Hook，本版不实现 State 服务。未来第一个真实消费者落地时，按
TOML、模块命名空间、未知字段保留、Runtime 单写者和 TSF 故障隔离设计。

## 9. FPSUnlock

FPSUnlock 未完成，但已迁入 SDK：强制 Runtime，使用 Hook、Render、Clock、GameState、Module、
TOML 和 Log，不再读取 Widescreen CALL 当前目标。它保持独立 `build.bat`，明确不进入 build_all。

## 10. ModLoader 改动

- 所有日志统一到 `mods/logs`；
- GameAudit 的状态 Hook 延后到 ASI 初始化后，遇到 Runtime 已改入口时严格跳过；
- 两阶段 ASI 初始化完成后发送 Loader-ready；
- 同名插件配置编辑器从 INI 改为 TOML；
- Loader 自身 INI 与 mods.ini 不受 Runtime 控制。

## 11. 构建合同

根 build_all 当前 10 项，不含 FPSUnlock。开始时删除自己负责的旧 Runtime/ASI/TOML/Quest 数据，
防止跳过步骤后陈旧文件假通过。最终发行检查要求：

- Runtime 与 8 个正式 ASI 存在；
- PE32/i386、DLL、非零入口和导出正确；
- 6 份正式同名 TOML 存在、旧 INI 不存在；
- Quest manifest 存在；
- SaveEnhance 随包说明存在；
- `build/mods/logs` 存在；
- build 无 obj/lib/exp/ilk/pdb。

## 13. 已踩坑

- 无 CRT Runtime 漏入 `_memcpy` 会在链接阶段失败；正式链接必须包含 runtime_crt_support；
- FARPROC 直接强转在 Clang `-Wcast-function-type-mismatch` 下失败，必须位模式复制；
- Runtime 测试 DLL 曾因缺少真实 PE 合同而出现 0xc000012f；现已验证 PE32/入口/依赖；
- Schedule 若在外层 InitializeASI 完成前启动，会让 Backlog/Controller“加载成功但完全不可用”；
- BAT 混合 LF/CRLF 被父脚本 call 时会吞行并产生 `Tfail` 等伪命令；构建脚本统一 CRLF；
- build_all 曾因 FPS/Quest 步骤被跳过而读取旧产物假绿；现在构建前精确清除旧正式文件；
- TOML 初迁移丢失详细注释；当前模板已逐键恢复，并有机械检查；
- ModLoader 编辑器若继续允许 ANSI/UTF-16，会与 Runtime UTF-8 解析边界不一致；现在明确拒绝。
