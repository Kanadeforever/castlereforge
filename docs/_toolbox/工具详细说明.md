# 项目工具箱详细说明

本目录说明 `src/_toolbox/` 中随仓库保存的三个辅助工具。它们只服务于合法持有的游戏文件、补丁安装包和本地目录；仓库不会提供游戏本体、`RPG.exe` 或受版权保护的原版资源。

运行 Python 源码需要 Python 3。使用前先复制一份待处理目录作为备份，不要直接对唯一一份游戏安装目录试验。工具产生的输出和报告也不应提交到仓库。

## Wise 补丁安装包解包器

源码：`src/_toolbox/补丁安装包解包_WiseTreeExtractor.py`

用途：在不执行旧 Wise 安装程序的前提下，直接解析安装包中的压缩数据和安装记录，按 CP950 解码目标路径，并重建 `%MAINDIR%` 下的目录树。工具使用文件大小和 CRC32 配对安装记录与内容，同时恢复安装记录中的 DOS/FAT 修改时间。

适用范围：本项目研究过的台湾 2001 年 Wise Installation System 补丁安装程序。未知安装器即使扩展名同为 `.exe`，也不保证使用相同格式。

命令行用法：

```text
python src\_toolbox\补丁安装包解包_WiseTreeExtractor.py 补丁安装程序.exe
```

也可以一次传入多个安装程序。成功后会在安装程序所在目录建立：

```text
<安装程序名>_Extracted\
<安装程序名>_extract_report.txt
```

只有报告末尾明确显示成功，且 `Big5/CP950 解码错误`、`CRC/大小未匹配`、`原始修改时间恢复失败` 均为 0 时，才可以使用解包结果。解包器不会自动把文件复制进游戏目录，也不会替用户判断是否应该覆盖现有文件。

## 乱码文件名修复工具

源码：`src/_toolbox/乱码修复.py`

用途：按照源码内冻结的文件名映射表，递归扫描工具所在目录及其子目录，修复一组已知乱码文件名，并保留扩展名。

该工具会真实重命名文件。为避免误处理仓库或其它游戏目录，应先把脚本复制到待修复目录的副本中，再从该副本运行：

```text
python 乱码修复.py
```

若目标文件名已存在，工具不会覆盖，而会追加 `_1`、`_2` 等序号。执行结果写入同目录 `rename_report.txt`。没有出现在内嵌映射表中的文件不会改名。

## 游戏文件验证工具

源码：`src/_toolbox/游戏文件验证.py`

用途：使用脚本内嵌的 SHA-256 清单检查其所在目录，报告目标文件缺失、哈希不符、未登记文件或读取失败。它只读取被检查文件，不修改游戏内容。

使用时把脚本复制到需要验证的游戏目录副本中，然后运行：

```text
python 游戏文件验证.py
```

结果写入同目录 `SHA256_VERIFY_REPORT.txt`。只有控制台和报告同时显示 PASS，才能说明目录与工具内嵌的目标清单一致；PASS 不能证明文件来源合法，也不能代替杀毒检查、游戏实机测试或 CastleReforge 模块验收。

## 安全边界

1. 不要对 `参考资料/` 执行会写入或重命名的工具；该目录在项目中只读。
2. 解包结果、游戏文件和验证报告不得冒充项目源码提交。
3. 乱码修复工具必须先在副本中试运行，并核对 `rename_report.txt`。
4. 文件验证失败时先阅读报告，不要通过删除未知文件或覆盖原文件来强行制造 PASS。
5. 工具本身不绕过版权、许可证、游戏平台或补丁发布方的使用条件。
