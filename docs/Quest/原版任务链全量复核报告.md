# 原版任务链全量复核报告

## 证据基线

现行 Base 继续建立在冻结 v0.6 任务研究、原版 RPG.exe.org 与用户补充的 `任务分析_0.1.5_原版事件空间数据` 上。dev6zc 已对 25 个任务的 Stage、Scene/Event/Object/坐标和顶层状态覆盖做全量复核。

## 已确认修正

Q002 彩石弹珠：Event37 写入后真实状态为 `Var505=1, Var1008=0, Var1007=1`；`find_doll.when` 原本正确，但 Quest 顶层漏掉这一可达状态。现行 Base 已在 `active_when` 与 `journal_when` 同时覆盖。

Q004 营救阿吉：Var504 才是任务主进度；Event32 写 Var503 不是阿吉任务进度，Event33 的“城外大蝎子”对白也不持久推进。因此四小鬼不属于原版硬性 Base Stage，dev6zd 已将旧 `optional_clues` 从 Base 删除。

Q001 主线开局：取鸡汤 Event18 是 Var1=0→1 的真实推进，仍属于 Base 原版任务链。

## 未强行猜测的 Marker 缺口

`mp0705 Event15` 与 `mp0601-2 Event21` 的 Event 本身存在，但原版事件空间仍不足以唯一证明 SCI 对象绑定，因此不凭空写假对象/坐标。缺口继续作为研究项，而不是运行数据猜测。

## 运行层与研究层

研究冻结资料仍可能保留过去用于取证的候选 Stage、失效警告和全局路由 CSV；这些不是现行运行数据库。现行 Runtime Base 只有 146 个真实 Stage，人工体验只来自 Addon。
