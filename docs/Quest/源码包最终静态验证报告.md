# Castle_Quest v0.1-dev6zd 源码包最终静态验证报告

> 本报告由封包阶段最终机械审计回写。Windows 游戏实机不在当前 Linux 会话中执行，不能用静态检查替代实机结论。

## 1. 主项目迁移与 SDK 接口

目录已经迁移为 `src/Quest/` 与 `docs/任务系统/`。Quest 不复制 RuntimeSDK；`build.bat` 只引用同级 `src/RuntimeSDK/include` 与 `src/RuntimeSDK/client`。

已按 2026-09-01 主仓公开 RuntimeSDK v1 头接口核对：插件导出使用 `CastlePlugin_Query / InitializeASI / CastleRuntimeClient_NotifyLoaderReady`；Integrated 的两个固定 E9 入口使用 Hook v1 `ExclusivePatch` 同事务提交；Standalone 才保留本地 `VirtualProtect`；Runtime Fault 不回退 Standalone。

## 2. manifest 与任务数据库机械审计

封包脚本重新使用标准 Python TOML 解析器读取全部运行文件，结果：

```text
运行 TOML = 51
Base = 25，全部 format_version=7
Addon = 25，全部 format_version=2
Base Stage = 146
Canonical = 146
Stage-local Route = 556
Addon Insert = 1
Warning = 0
Guidance = 0
```

`manifest.toml` 已逐字段与实际文件复算一致：`format_version=7`、`database_version=research-v0.6+dev6zd-runtimesdk-migration`、`quest_count=25`、`addon_count=25`、`stage_count=146`、`canonical_stage_count=146`。构建脚本把这些值作为发行闸门，而不是只相信 manifest 自己。

全量数据/目录审计共 216 项，216/216 PASS；其中包含 Base/Addon quest_id 配对、所有 override 目标存在、唯一 Insert 的 after/before 相邻性、Q001/Q002/Q004 关键状态、文档命名和 src 文档位置规则。

## 3. 旧体系删除

运行 Base 不再存在 `stage_type`、`guidance_scene`、`[[warning]]`。Q004 Base 不再存在 `optional_clues`；唯一人工调查由 Addon Event33 Insert 承担。源码也不再存在 Guidance 类型选择器、热重载清空 Addon 完成集合的代码，或按 `Available/Unavailable` 擦除完成键的旧猜测式清理。

## 4. 语法与工具检查

- `RouteSearch.cpp`：Clang C++17 `-Wall -Wextra -Werror -fsyntax-only` PASS。
- `CastleQuest.cpp`：使用**包外** Win32/DirectDraw/RuntimeSDK v1 声明桩执行 Clang C++17 语法检查 PASS；声明桩不进入源码包，只用于当前非 Windows 环境检查迁移改动的 C++ 结构。
- `CastleScriptAnalyzer.py`：`py_compile` PASS；`--self-test` PASS。
- `build.bat`：UTF-8 无 BOM + CRLF；全部 `rem` 与带文字 `echo` 行末两个半角空格；包含 RuntimeSDK Client 文件存在性、manifest 实数复核、PE32/x86、导出名和 `/MT` 依赖检查。

## 5. 编译边界

当前 Linux 环境没有 Windows SDK/MSVC x86 链接环境，也没有可用 i686 MinGW-w64，因此本包**没有生成或伪造 `build/` 和 `.asi`**。真实主仓编译必须由 `src/Quest/build.bat` 在 Windows 主项目环境完成；成功后它只发布 Quest 自己的 ASI、INI 和 51 个任务 TOML，不清理其它子项目发行文件。

## 6. 仍需实机验收

合并主仓后需要验证 Integrated、Standalone、Runtime Fault 三路生命周期，宽屏并存、Ctrl+F7/F8/F11、Q002 `find_doll`、Q004 Addon Insert，以及实际 Loader 导出调用。静态 PASS 不等于这些实机项已经完成。
