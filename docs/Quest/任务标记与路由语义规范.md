# Castle_Quest dev6zd 任务标记与路由语义规范

Marker 必须尽量绑定原版真实 Event/对象/TouchBox，而不是用猜测坐标替代原版空间事实。

EVENT_MANUAL 目标使用当前场景实际 RuntimeEntity/SCI 的 Manual EB 关系；TOUCH_EA 必须有真实 TouchBox，找不到 TouchBox 时不能自动退化成某个实体中心。显式人工世界坐标只作为已确认例外，必须通过 `manual_world_x/manual_world_y` 明示。

Stage-local Route 继续使用条件化 BFS。跨场景时当前 Stage 自己持有安全出口边，不存在全局运行 `routes.toml`。

Ctrl+F11 继承 dev6y 已验收命中修复：首选原版 MouseWorld `0x0089F7C0/0x0089F7C4`，再与 Marker/实体框使用同一世界到 Surface 投影；Win32 客户区换算只作显式 Fallback。dev6zd 的 SDK 迁移没有修改这条路径。

Integrated 模式只改变两个入口机器码由谁写：Runtime Hook 事务拥有 E9 补丁；Marker、路由和任务状态语义不因 SDK 接入而改变。
