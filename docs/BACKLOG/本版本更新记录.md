# 本版本更新记录

## 零点二版

- 继承零点一版已经实机可工作的记录、打开、浏览、退出、输入门和环形历史；
- 记录新增最多 64 字节 NameList 姓名快照；
- 展示从固定底框单条替换改为同屏最多四个原版 F-Talk 对话框的纵向现代列表；
- 有姓名记录使用左侧姓名列、右侧正文；无姓名记录保持原版左边距；
- 按用户要求，现代列表完全不显示人物图；
- 删除浏览期 `0x403C60` 调用，不卸载/重建人物 `%d-2.SF2`；
- 修复用户实机报告的 `FrameID >= m_SafHeader->TotalFrameNumber` 跨人物报错路径；
- 新增 `0x40486E` 通用框 draw CALL 与 `0x4049FF` 正文 draw CALL 的窄链式 Hook；
- 默认 `PageSize` 从 5 改为 4，与同屏条数一致；
- 机器预检和检查器新增两处 CALL 签名；
- 构建脚本在同步前清理两个明确文档镜像中的旧 Markdown，避免改名后残留旧接档。

零点一版底层主链实机可用、人物回放明确 FAIL；零点二版现代无人物展示已静态/构建 PASS，待用户实机复核。详细状态以《截至零点二版的完整接档》为准。
