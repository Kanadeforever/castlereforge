# Castle Backlog 使用与配置说明

## 安装

```text
mods\asi\Castle_Runtime.dll
mods\asi\Castle_Backlog.asi
mods\asi\Castle_Backlog.toml
```

Backlog 可以脱离 Castle Mod Loader 和其它业务插件，由兼容的 x86 ASI Loader 加载，但官方版
不能脱离 Runtime。需要手柄时再同时启用 Castle_PadSupport 和兼容 x86 SDL3；没有手柄 Provider
时键盘、鼠标仍正常。

## 默认操作

| 功能 | 键盘/鼠标 | 手柄 |
|---|---|---|
| 打开 | B 或未打开时滚轮向上 | LB |
| 上一条 | ↑ 或滚轮向上 | 十字键上 |
| 下一条 | ↓ 或滚轮向下 | 十字键下 |
| 向旧翻页 | ← | 十字键左 |
| 向新翻页 | → | 十字键右 |
| 退出 | B/ESC/鼠标右键 | LB 或语义取消键 |

Backlog 打开时会取得 Runtime Input Focus 和 Dialogue Mutation Lease，避免按键穿透其它覆盖层，
也避免多个插件同时临时修改对话绘制状态。

## 可用状态

普通对话和稳定剧情消息可打开；无对话时只允许自由探索。标题、战斗、主 Interface、客栈、
炼化、商店、存档、电影和已知模态 UI 拒绝打开。没有任何历史时不会打开；历史只存在于当前
RPG.exe 进程。

## TOML

配置文件使用 UTF-8 TOML。每个键的详细说明已经写在模板中，主要范围如下：

- `Backlog.Enabled`：1 启用，0 停用；
- `MaxEntries`：历史容量；
- `PageSize`：翻页跨度；
- `PanelStrideY`：80～160；80～110 同屏最多四条，111～160 最多三条；
- `RepeatDelayMs`：长按首次连发延时；
- `RepeatIntervalMs`：后续重复间隔；
- `Keyboard.*`：省略 `VK_` 的 Win32 Virtual-Key 名称。

默认 `PanelStrideY=160`。Runtime TOML 会对数值执行插件给出的安全范围；未知字符串键回退默认。
修改后重启游戏生效。

## 手柄联动

Backlog 通过 Runtime Input 读取快照，不再按 ASI 文件名调用 `CastlePad_GetApi`。PadSupport 缺失或
Provider 未 ready 时只关闭手柄联动，不影响键鼠。

调查模式、RT 临时鼠标和 Back 常驻鼠标模式中，Backlog 忽略手柄输入；这由 Input 快照语义决定，
不是扫描 PadSupport 内部状态。

## 日志

```text
mods\logs\Castle_Backlog.log
```

日志由 Runtime Log 创建和刷新。提交问题时附 RPG.exe SHA-256、ASI 加载顺序、是否启用手柄/
宽屏、发生问题的地图或对话以及日志全文。
