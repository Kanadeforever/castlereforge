# 使用与配置说明

## 安装

把以下两个文件一起放进 Castle Mod Loader 的 `mods\asi`：

```text
Castle_Backlog.asi
Castle_Backlog.ini
```

如果要使用手柄，`SDL3.dll` 也应位于加载器可用的同一 ASI 目录；已经安装手柄插件时通常本来就存在。没有 SDL3 时无需补文件，键盘仍能完整工作。

## 默认操作

| 状态 | 键盘 | 手柄 |
|---|---|---|
| 打开 | B | LB |
| 上一条（更旧） | ↑ | D-Pad ↑ |
| 下一条（更新） | ↓ | D-Pad ↓ |
| 向旧翻页 | ← | D-Pad ← |
| 向新翻页 | → | D-Pad → |
| 退出 | B | East（Xbox B 位置） |

打开时同屏最多显示四条原版 F-Talk 对话框，最新记录位于最下方，更旧记录依次向上。现代列表不显示人物图；有说话人时只在该条左侧显示姓名文字，正文位于右侧。上/下到端点后继续按会首尾环回；左/右按页跳转并停在边界。方向键可长按。

## 可用状态

有原版对话框时可以打开，包括普通文字与剧情选择前后的消息状态。没有对话框时只有自由探索可打开。标题、战斗、主 Interface、客栈、炼化、商店、存档、电影和已知模态 UI 均会拒绝。

没有任何已记录对话时不会打开；历史只存在于本次 RPG.exe 进程，退出游戏会清空。

## 配置格式

### Backlog

- `Enabled`：0 关闭，非 0 开启；
- `MaxEntries`：16～256，默认 128；
- `PageSize`：2～32，默认 4，正好跳过一整屏；
- `RepeatDelayMs`：长按开始重复前的等待，100～2000；
- `RepeatIntervalMs`：长按重复间隔，40～1000。

### Keyboard

值是 Win32 Virtual-Key（KB）码，支持十进制与 `0x` 十六进制。例如：

```ini
Open=0x42
Exit=0x42
Up=0x26
Down=0x28
Left=0x25
Right=0x27
```

### Gamepad

值是 SDL3 标准 Gamepad 名字，忽略大小写、空格、横线和下划线。支持：

```text
south east west north
back guide start
left_stick right_stick
left_shoulder right_shoulder
dpad_up dpad_down dpad_left dpad_right
misc1 misc2 touchpad
left_paddle1 right_paddle1 left_paddle2 right_paddle2
```

别名包括 `a/b/x/y`、`lb/rb`、`l3/r3`、`select`。这里的 A/B/X/Y 是 SDL 的物理位置别名；跨品牌手柄建议使用 `south/east/west/north`，避免字母印刷差异。

## 日志

ASI 同目录会生成 `Castle_Backlog.log`。提交问题时请附：RPG.exe SHA-256、ASI 加载顺序、是否安装手柄/宽屏、SDL 是否存在、发生问题的地图/对话和日志全文。

## v0.3.3-test3 当时打开规则（历史）

- 自由探索：可打开，使用 synthetic dialogue 绘制载体。
- 普通稳定剧情：`dialogue_id` 为真实剧情、`mode=0/1`、`current=target=4` 时可打开，使用零写入剧情旁路。
- 剧情正在展开/切页：本次打开请求忽略，等稳定后再次操作。
- `mode=2/3`、剧情选择以及未知特殊消息：当前拒绝打开。
- 战斗、主 Interface、商店、客栈、炼化、存档、电影等已知模态 UI：继续拒绝。

手柄要求安装带 Public API v1 的 PadSupport；否则只使用键盘/鼠标。


## v0.3.3-test4 当前运行方式

- 自由探索：建立 synthetic dialogue，并继续让原版 SceneWorld update 运行，以维持消息绘制载体；地图/事件输入仍被 Backlog 门控。
- 普通稳定剧情：进入零写入剧情旁路，并完全冻结 SceneWorld update。
- 两条路径都使用同一套历史四框绘制 Hook；区别只在于是否允许原版 update 继续执行。
- INI 配置项没有新增或改名。

## v0.3.4-test2 安全间距（历史）

`PanelStrideY` 仍是同一配置名，但有效范围改为 80～110，默认 110。旧配置 118 或更大无需手工删除，
运行时会自动夹到 110。这个上限用于保证第四条姓名仍在屏幕内，不能再把 160 当作有效“更松”选项。

## v0.3.4-test3 自适应间距（当前）

- `PanelStrideY=80..110`：同屏最多四条；
- `PanelStrideY=111..160`：同屏最多三条；
- 默认 `135`，用户写入的 135 会真实生效；
- 左右翻页量自动夹到当前三/四条容量。

三条模式在最大 160 时，最上姓名 Y 仍为 25，不需要再牺牲配置效果。
