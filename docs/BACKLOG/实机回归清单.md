# Castle Backlog v0.3.1-test1 实机回归清单

> 本清单与《完整接档说明.md》对应。先测崩溃，再测输入；任何崩溃出现时停止后续项目并保存 `Castle_Backlog.log`。

## 一、NPC 历史崩溃

- [ ] 与 NPC A 连续产生至少 3 条有姓名页面，退出对话，再按 B 打开 BACKLOG。
- [ ] 关闭后与 NPC B、NPC C 各产生数条有姓名页面，再回自由探索打开。
- [ ] 历史列表同时出现不同 NPC 姓名时不崩溃。
- [ ] 连续滚动到更旧/更新的不同 NPC 记录不崩溃。
- [ ] 反复“打开 → 关闭 → 新 NPC → 再打开”至少 10 次不崩溃。
- [ ] 若日志出现 `F-Name 对象没有通过已加载 SF2 协议检查`，游戏仍稳定；该次允许只显示姓名文字而没有姓名牌。

## 二、姓名框与正文布局

- [ ] 有姓名条目正文不再向右缩 96 像素。
- [ ] 左侧姓名位于正文上方约 35 像素。
- [ ] 右侧姓名位置正确。
- [ ] F-Name 可用时有姓名牌，且姓名文字与姓名牌对齐。
- [ ] 无姓名条目只有 F-Talk，不凭空出现姓名牌。
- [ ] 长句不提前撞右边界。

## 三、INI

- [ ] `Open=B` / `Exit=B` 正常。
- [ ] `Up=UP` / `Down=DOWN` / `Left=LEFT` / `Right=RIGHT` 正常。
- [ ] 临时把某项改成 `VK_B`，仍能兼容识别。
- [ ] 临时把某项改成旧 `0x42`，仍能兼容识别。
- [ ] `PanelStrideY=110` 比默认更紧。
- [ ] `PanelStrideY=125` 比默认更松。
- [ ] 极端小于 80 或大于 160 的值被源码安全裁剪。

## 四、鼠标

- [ ] BACKLOG 关闭时，滚轮向上可打开。
- [ ] BACKLOG 打开后，滚轮向上查看更旧记录。
- [ ] BACKLOG 打开后，滚轮向下查看更新记录。
- [ ] BACKLOG 打开后，鼠标右键退出。
- [ ] 右键退出时底层地图/UI 不同时收到一次右键点击。
- [ ] Alt+Tab 到其它程序后滚轮/右键不会累积成切回游戏后的误操作。

- [ ] BACKLOG 正常加载。
- [ ] 键盘和鼠标全部正常。
- [ ] 不需要 `SDL3.dll`。
