# 第三方依赖说明

## 零点二版状态

现代四框列表仍没有新增第三方依赖。对话框来自原游戏 F-Talk 资源，姓名与正文来自原字体；人物图明确不加载。

## 必需依赖

无第三方必需依赖。ASI 链接时只导入 Windows 自带的 KERNEL32.dll 与 USER32.dll。

## 可选 SDL3

SDL3 只用于手柄。插件不包含 SDL 代码、不静态链接 SDL、不导入 SDL3.dll，也不需要 SDL SDK/头文件。

运行时顺序：

1. 先用 `GetModuleHandleA("SDL3.dll")` 复用手柄插件已经加载的模块；
2. 如果尚未加载，只从 Backlog ASI 同目录尝试 `LoadLibraryA`；
3. 逐个取得 Gamepad 所需导出；
4. 任一步失败都只关闭手柄输入，键盘保持完整；
5. 不调用 SDL_Quit、不读取/清空 SDL 事件队列、不关闭别的插件句柄。

当前必需导出：`SDL_Init`、`SDL_UpdateGamepads`、`SDL_GetGamepads`、`SDL_OpenGamepad`、`SDL_CloseGamepad`、`SDL_GamepadConnected`、`SDL_GetGamepadButton`、`SDL_free`。

SDL 的许可证与实际随发行包提供的 SDL3.dll 版本应由上游手柄插件/发行包统一携带。本插件源码包没有复制 SDL 二进制。

## 检查器

`backlog_check.py` 只使用 Python 标准库，没有 pip 依赖。
